# Idea: pigment-network state vector rather than one colour/flux axis

## Origin of the problem

This idea is generated by the quantitative `chun` meta-analysis, not by a literature future-work statement.

The earlier directional synthesis used a deliberately coarse field, `competing_branch_more_active_in_less_red`, to capture evidence that some non-anthocyanin deployment increases in less-red/white/yellow comparisons. Quantitative recovery from the Zhou2020 *C. sinensis* white-versus-pink supplements shows that this binary representation is too compressed.

After a provenance gate demonstrated that Table S6 has systematically reversed BTP/ZJW headers (16/16 overlapping gene-stage triplets match only after swapping; Table S8/S9 retain the article mapping ZJW=white and BTP=pink), the corrected 30-sample profile gives:

- DFR: 15/15 gene-stage observations shift toward pink;
- FLS: 5/10 gene-stage observations shift toward pink and becomes white-directed at late stages;
- LAR: 10/10 gene-stage observations shift toward pink;
- anthocyanin-minus-flavonol relative shift: positive in 5/5 stages;
- anthocyanin-minus-proanthocyanidin relative shift: positive in only 3/5 stages.

Therefore flavonol and proanthocyanidin deployment cannot be treated as one interchangeable `competitor` axis. A pink state can simultaneously increase anthocyanin and LAR/PA-associated deployment while diverging from FLS later in development.

An independent *C. reticulata* red/pink/white system is being quantified in the same PR using its complete reported 61,277-gene expression table and 310-compound metabolite table. This second system is used as an independent check, not pooled as extra observations within the *C. sinensis* cluster.

## Primary hypothesis — H_PATHWAY_STATE_VECTOR

A biologically useful Camellia flower-pigment state is a **multidimensional allocation vector**, not a scalar redness or anthocyanin-versus-competitor score.

Minimum current representation:

`P = [anthocyanin, flavonol, proanthocyanidin, carotenoid]`

Each component should ultimately carry both:

- deployment/intensity;
- node/paralog identity and regulatory route.

Visible hue is then an observation generated from this biochemical state together with pH, co-pigmentation, cell structure and optical/sensory properties rather than the state itself.

## Consequence for accessibility

`H_ACC` should not be interpreted as all genes in the flavonoid pathway moving together. Accessibility is hierarchical:

1. **node/paralog accessibility** — which specific regulatory or structural loci repeatedly switch;
2. **module accessibility** — which biochemical branch changes net deployment;
3. **phenotype realization** — how the combined vector maps to pigment chemistry and spectrum.

This matters because broad KEGG enzyme families can contain paralogs moving in opposite directions while a small subset of late functional nodes tracks pigment state strongly.

## Consequence for micro-to-macro reuse

`H_MICRO_MACRO_REUSE` should be tested at two resolutions:

- enrichment of high-accessibility **nodes/paralogs** on independent macro transition branches;
- similarity of the resulting **module-state vector displacement** across independent transitions.

A macro transition should not count as reuse merely because any gene in a large pathway family changed.

## Consequence for ecology

Selection-pressure analyses should compare ecology to the latent vector and its sensory projection, not to W/A/Y alone. Different vector components may have different functions:

- anthocyanins: visible/UV signal and possible stress protection;
- flavonols: co-pigmentation/UV and pathway allocation;
- proanthocyanidins: distinct downstream allocation that need not oppose anthocyanin in expression;
- carotenoids: independent yellow/red contribution.

Therefore `H_SELECTION_TARGET` becomes a test of whether ecological/pollinator events align with particular vector components or combinations.

## Data needed before macro use

Public-data work first:

- common ortholog/paralog mapping across admitted transcriptomes/genomes;
- common within-study module scores for anthocyanin, FLS/flavonol, LAR/ANR/PA and carotenoid modules;
- matched metabolite evidence where processed tables are public;
- node-level accessibility scores with study/lineage dependence retained.

New biological measurements are required only where the public matrix remains structurally missing, especially standardized petal pigment chemistry and reflectance/UV on the same phylogenetic species set.

## Claim boundary

Current quantitative evidence is sufficient to reject a single undifferentiated `anthocyanin versus all competing branches` representation in at least the *C. sinensis* system. It does **not** establish that four dimensions are sufficient genus-wide, nor that any one component is the adaptive target. The state-vector representation is a model refinement generated by the data and must be tested across independent systems and nuclear branches.
