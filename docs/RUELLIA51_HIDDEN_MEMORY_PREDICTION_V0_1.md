# Ruellia51 held-out hierarchical hidden-memory prediction — v0.1

## Prediction

The Flower-clades-51 exploratory extension found that fine flower-color states often retain phylogenetic organization **inside** coarse color states even when fine resolution does not globally win.

That result is post-outcome. *Ruellia* remains outcome-unopened for the CHUN HPLC profile and therefore provides a held-out test.

If the frozen *Ruellia* common frame contains genuine fine→coarse compression opportunity, we predict that fine anthocyanidin-composition states will be phylogenetically organized within the coarse anthocyanidin-presence state.

## Existing hierarchy is untouched

This test inherits the already-frozen HPLC hierarchy:

- coarse: any of six anthocyanidins present versus none;
- intermediate: PEL/CYA/DEL branch-presence pattern;
- fine: exact six-anthocyanidin presence pattern.

No threshold, state definition, common-frame rule, tree rule or sample aggregation rule is changed.

## Opportunity gate

Before any hidden-memory statistic is computed:

`fine_state_count > coarse_state_count`

must hold on the frozen retained-tip frame.

If not, terminal status is:

`STRUCTURAL_NO_HIDDEN_MEMORY_TEST`

because no fine distinction exists inside a coarse state to test.

## Conditional estimator

If opportunity exists:

1. keep only unordered retained-tip pairs that share the same coarse state;
2. score pairs by negative patristic distance;
3. label whether each pair also shares the same fine state;
4. calculate the conditional ROC AUC;
5. shuffle fine labels within each coarse group, preserving fine-state counts;
6. repeat for 9,999 permutations, seed 20260920.

The conditional null AUC is not assumed to equal 0.5. The observed AUC is compared to the permutation distribution generated by the frozen coarse membership and fine-state counts.

PASS requires:

- observed conditional AUC > permutation mean;
- one-sided permutation P <= 0.05.

## Independent from the earlier global-tilt prediction

PR #313 already froze a different prospective prediction:

`AUC_fine > AUC_coarse`

when compression opportunity exists.

The two predictions answer different questions.

- global tilt: does fine coding outperform coarse coding overall?
- hidden memory: are fine states organized within a coarse phenotype?

Neither result can rescue the other after outcome opening.

A clade can in principle fail the global tilt prediction while passing the hierarchical hidden-memory test.
