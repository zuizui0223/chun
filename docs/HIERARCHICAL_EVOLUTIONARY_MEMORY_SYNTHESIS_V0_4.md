# Hierarchical evolutionary memory synthesis — v0.4

## Current conclusion

The hierarchical-memory programme now supports a stronger and more specific statement than “flower colour has phylogenetic signal.”

**Fine flower-colour states repeatedly retain lineage history inside broader phenotype classes, and this hidden history is a distinct evolutionary coordinate rather than a trivial by-product of how phenotype states are grouped.**

The architecture is recurrent in visible colour and has one independent prospective visible-colour replication. It is not universal across all representations, and its biological causes remain unresolved.

## Evidence foundation

Across the 21 standardized visible-colour radiations with genuine fine-to-coarse opportunity:

- 18/21 have positive hidden-memory effects;
- median centered effect = +0.0270 AUC;
- one-sided Wilcoxon P = 3.34 × 10^-5;
- sign-test P = 7.45 × 10^-4.

The independent prospective Schistanthe test passed:

- retained tips = 129;
- centered effect = +0.06416 AUC;
- P = 0.0033.

Biochemical evidence remains mixed:

- Petunieae retrospective effect = +0.18794 AUC, P = 0.0001;
- Gesnerioideae prospective effect = -0.00779 AUC, P = 0.5005, frozen FAIL.

Thus hidden memory is recurrent, but a universal cross-representation law is not supported.

## What hidden memory is not

### 1. Not a trivial state-compression artifact

The frozen structural prediction was: more fine-to-coarse pair collision should produce stronger hidden memory.

Observed:

- rho = -0.2571;
- 99,999-permutation P = 0.26023;
- all 21/21 leave-one-clade-out correlations remain negative.

So the positive cross-radiation hidden-memory pattern is not explained by simply putting more fine states into the same coarse bin.

Opportunity is necessary to define the test, but the amount of opportunity does not determine realization.

### 2. Not equivalent to unconditional global signal

Among the 21 opportunity clades, 10 had previously been classified as PROFILE_NO_PHYLOGENETIC_SIGNAL.

Yet within those 10:

- 8/10 hidden-memory effects are positive;
- median centered hidden effect = +0.02754 AUC.

The frozen exact sign test narrowly misses the threshold:

- P = 0.05469.

Therefore cryptic memory is not promoted as a subgroup-level inferential result.

Still, the descriptive mismatch matters: a global “no signal” classification does not imply that all nested lineage organization is absent.

### 3. Not equivalent to a global fine-resolution persistence advantage

The frozen temporal-realization test asked whether radiations with greater integrated fine-colour persistence across relative evolutionary divergence also have stronger hidden memory.

Observed:

- rho = +0.41818;
- 99,999-permutation two-sided P = 0.06147;
- all 21/21 leave-one-clade-out correlations are positive;
- bootstrap 95% interval = +0.0171 to +0.7081.

The direction is stable, but the frozen primary rule is not met.

More importantly, the relation between hidden memory and fine-minus-coarse persistence area is weak:

- rho = +0.1078, P = 0.642.

So hidden memory is not simply another name for “fine resolution globally persists longer.”

## Four distinct questions

The programme now separates four biological/analytical coordinates.

1. Opportunity — are there actually multiple fine states inside a coarse phenotype?
2. Global signal — does phenotype identity show unconditional phylogenetic organization across the radiation?
3. Temporal persistence — how much exact fine-state similarity survives as lineages diverge?
4. Hidden realization — after coarse membership is fixed, how much additional fine-state lineage organization remains?

A fifth quantity, informativeness, is a design property: whether a frozen test has enough null resolution to adjudicate a benchmark-sized effect.

These quantities can differ within the same radiation.

## Biological interpretation

A broad flower phenotype can act as one ecological or display class while still containing several lineage-specific evolutionary histories.

Coarse-graining therefore does not simply remove information. It can hide structured history inside a broad state.

The amount of hidden history varies among radiations. That variation is not explained by simple coding geometry and is not reducible to the global resolution winner.

This makes hidden-memory realization itself a macroevolutionary property that needs explanation.

Candidate causes include transition dynamics, lineage-specific developmental constraints, pollinator selection, or ecological heterogeneity. None is presently established.
