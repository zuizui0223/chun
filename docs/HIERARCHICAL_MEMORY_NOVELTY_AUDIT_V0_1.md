# Hostile novelty audit — hierarchical evolutionary memory v0.1

## Decision

The new hierarchical-memory synthesis is biologically stronger than the frozen v0.3 “no universal scale” framing, but its novelty must be bounded carefully.

The safe novelty claim is **not**:

> fine information can have phylogenetic signal inside a coarse flower-color phenotype.

That phenomenon has important prior art.

## Closest prior art

### Ng & Smith 2016 — developmental pathway signal within convergent red flowers

Ng & Smith asked whether closely related red-flowered Solanaceae tend to use the same pigment pathway. Anthocyanin use and dual anthocyanin+carotenoid use showed phylogenetic signal.

DOI: `10.1111/nph.13576`.

This is conceptually close to hidden memory: a shared coarse visible phenotype does not erase phylogenetic information in the underlying mechanism.

Therefore CHUN must not claim that it is the first study to show within-phenotype mechanistic phylogenetic signal.

### Ng, Freitas & Smith 2018 — pathway structure shapes phenotype transitions

The Solanaceae anthocyanin study showed that transitions among pelargonidin, cyanidin and delphinidin states are stepwise and reflect the organization of the flavonoid pathway.

DOI: `10.1111/evo.13589`.

Therefore CHUN must not claim that hierarchical or constrained flower-color state spaces are themselves newly discovered.

### Aggregated-state-space theory

Weber, Perron & Casey showed in molecular sequence models that inference in an aggregated state space depends on the mapping from the richer underlying state space.

DOI: `10.1093/sysbio/syaa036`.

This is not a flower-color study, but it prevents a broad priority claim that phylogenetic information loss under state aggregation is a new statistical idea.

## What remains genuinely different

The current CHUN extension contributes a **cross-radiation architecture**, not an isolated existence proof.

### 1. Standardized prevalence across clades

One identical conditional logic is applied across the standardized Flower-clades-51 batch:

- 21 clades have genuine fine→coarse opportunity;
- 18/21 have positive within-coarse hidden-memory effects;
- median permutation-centered effect = +0.0270 AUC;
- clade-level Wilcoxon P = 3.34 × 10^-5.

This asks how recurrent the architecture is across radiations rather than whether one example exists.

### 2. Hidden memory is separated from global winner status

The programme explicitly distinguishes:

- **memory amplitude** — how much history remains;
- **global scale tilt** — which representation looks stronger overall;
- **hierarchical hidden memory** — whether additional fine organization remains after coarse state membership is fixed.

The visible batch shows that hidden fine memory can remain positive even when a clade is globally coarse-tilted.

That distinction is the conceptual advance over a simple “pathway has signal” result.

### 3. Cross-representation bridge

Petunieae gives the same biological pattern in biochemical compound space:

- conditional AUC = 0.7018;
- within-coarse null mean = 0.5139;
- centered effect = +0.1879;
- P = 0.0001.

This remains retrospective and is one biochemical radiation, but it demonstrates that the architecture is not limited to human-visible color categories.

### 4. Independent external concordance without invalid pooling

Linoideae, Angraecinae and Antirrhineae already show conditional fine-state organization in three independent radiations using source-faithful but different estimators.

These systems are retained as a separate evidence tier rather than pooled with the standardized AUC results.

### 5. A real prospective gate exists

The *Ruellia* HPLC hidden-memory prediction was frozen before row-level HPLC state patterns or CHUN AUCs were opened.

The result remains unknown because the authoritative tree provenance is unresolved.

This is the key future falsification rather than another retrospective search.

## Strongest defensible novelty wording

> **The programme generalizes isolated observations of within-phenotype mechanistic phylogenetic structure into a cross-radiation architecture: fine phenotype identity often retains additional historical organization after coarse state membership is fixed, and this hierarchical memory is distinct from both overall memory strength and the globally best phenotype resolution.**

This wording does not depend on an absolute “first.”

## What not to say

Do not claim:

- first evidence that closely related species use the same pigment mechanism within one visible color;
- first phylogenetic signal of developmental pathways;
- first recognition that state aggregation changes phylogenetic information;
- universal fine-resolution superiority;
- universal hierarchical-memory law before the held-out *Ruellia* test is resolved.

## Manuscript implication

A future post-v0.3 paper should lead with:

> **Evolutionary history is stored hierarchically across phenotype scales.**

The old “no universal scale” result then becomes a consequence:

> no single scale must win globally because different layers of the phenotype can simultaneously retain different components of history.

That is a positive biological model rather than a collection of failed universal rules.

Frozen Evolution Letters v0.3 remains unchanged.
