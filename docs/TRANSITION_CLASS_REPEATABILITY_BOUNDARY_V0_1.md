# Transition-class repeatability boundary v0.1

## Why this boundary is needed

The cross-clade benchmark now contains gains, losses, regains and hue shifts, but the programme should not claim that it newly discovered a generic gain-versus-loss asymmetry.

Sobel & Streisfeld 2013 (`10.3389/fpls.2013.00321`) already argued from anthocyanin-pathway structure that losses can be produced by many disabling changes, whereas gains of floral anthocyanin usually draw from a narrower set of regulatory possibilities because the pathway is often retained in non-floral tissues. That mutation-spectrum argument is prior art.

## What the current atlas adds as a testable direction

The stronger question is not:

> Are gains more repeatable than losses?

It is:

> **At what biological level is a given flower-colour transition repeatable—exact gene, regulatory class, pathway module, core multivariate module, or complete pigment-state programme?**

The current evidence already rules out a universal answer based on direction alone.

### Gain / regain examples

- *Camellia* anthocyanin-gain systems: standardized whole A/F/C/P recurrence is only 1/3.
- *Petunia*: two independent regains share an R2R3-MYB regulatory class, but the exact implementations differ.

Thus a narrow mutational target set can create recurrence at a regulatory **class** without requiring exact mechanistic replay.

### Loss examples

- Iochrominae: four robust pigment losses converge strongly at the late-pathway module.
- Aquilegia: repeated anthocyanin losses likewise implicate late-pathway downregulation.
- Cape Erica: derived white/yellow endpoints are much more heterogeneous, with multiple focal causal nodes.

Loss therefore does not imply low repeatability; some loss classes can be strongly constrained at pathway level while others are mechanistically diffuse.

### Hue-shift example

Ipomoea red shifts provide a high-repeatability case at a specific regulatory target, illustrating that biochemical pathway topology can narrow the accessible route even when the transition is not a simple pigment on/off change.

## Working hypothesis

`repeatability_level = f(transition chemistry, pathway topology, pleiotropic constraint, retained latent capacity, observation regime)`

Direction (`gain` / `loss`) is one component of this architecture, not the primary universal predictor.

A practical hierarchy for future cross-clade coding is:

1. exact mutation / gene copy;
2. exact regulatory target;
3. regulator class;
4. pathway branch or module;
5. multivariate pigment-state package;
6. visible endpoint.

Each event or endpoint is coded at the finest supported level and can then be coarsened upward. Missing fine-scale information is never interpreted as evidence of recurrence.

## Novelty boundary

Do **not** claim priority for:

- gains having a smaller mutational target set than losses;
- regulatory evolution being common in flower-colour evolution;
- pathway-level convergence;
- retained anthocyanin machinery preserving regain potential.

The prospective atlas contribution is instead the **harmonized cross-clade measurement of the biological level at which repeatability survives**, while keeping event independence, trait organ, transition class and observation regime explicit.

## Current status

This is a hypothesis/prior-art boundary and benchmark interpretation. It is not yet a pooled statistical meta-analysis. The current systems have different denominators and ascertainment regimes, so no global recurrence probability is estimated.

Paper 1 remains unchanged and closed.
