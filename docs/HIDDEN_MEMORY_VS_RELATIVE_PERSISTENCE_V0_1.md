# Hidden memory versus relative fine-colour persistence — v0.1

## Frozen primary result

The primary prediction was fixed before this calculation:

> Clades with greater integrated persistence of exact fine flower-colour identity through relative evolutionary divergence should show stronger within-coarse hidden fine-state memory.

Across the 21 existing hidden-memory opportunity clades:

- Spearman rho = **+0.41818**
- 99,999-label-permutation two-sided **P = 0.06147**
- frozen decision = **NOT SUPPORTED**

The point estimate is in the predicted direction, but the predeclared P <= 0.05 criterion is not met.

## Robustness

The direction is unusually stable even though the frozen primary test misses the threshold.

Leave-one-clade-out:

- positive rho = **21/21**
- negative rho = **0/21**
- range = **+0.3669 to +0.4992**

20,000 clade bootstraps:

- median rho = **+0.41284**
- 95% interval = **+0.01710 to +0.70812**
- positive fraction = **0.9786**

These are robustness descriptors. They do **not** rescue the failed primary rule, and the expected positive direction is not used to switch post-outcome to a one-sided test.

## Secondary descriptors

Secondary relations were frozen as descriptive only:

- fine persistence slope vs hidden memory: rho = **−0.1779**, P = 0.440
- fine near–far contrast vs hidden memory: rho = **+0.1766**, P = 0.444
- fine-minus-coarse persistence area vs hidden memory: rho = **+0.1078**, P = 0.642

The last result is especially useful conceptually: hidden memory is not simply the same thing as a global fine-over-coarse persistence advantage.

## Evolutionary interpretation

The current data suggest, but do not establish, a temporal realization link.

Radiations in which exact fine flower-colour identity remains more strongly retained across relative evolutionary divergence tend to have stronger fine-state organization inside coarse states. The association is moderate and stable to leaving out any one clade, but falls just short of the frozen randomization criterion.

At the same time, hidden memory is nearly unrelated to **fine minus coarse** persistence area. That reinforces the architectural distinction already visible elsewhere in CHUN:

1. overall persistence of a fine phenotype through divergence;
2. which resolution has the largest global signal;
3. how much fine lineage history remains hidden inside a coarse state.

These are related questions, not interchangeable statistics.

## Boundary

This is post-outcome exploratory work using two summaries derived from the same source trees and colour states. It is not independent replication and cannot establish a causal mechanism.

No post-outcome one-sided test is opened. No alternative persistence metric becomes primary. No absolute-time claim is made.

A clean future test would freeze the positive relation in a new independent radiation set before hidden-memory outcomes are opened.

Frozen Evolution Letters v0.3 and Camellia Paper 1 remain unchanged.
