# Source-first prospective hidden-memory replacement screen — v0.1

## Why the search strategy changes

Two clean prospective replacement attempts failed before any hidden-memory outcome was opened:

- Merianieae: source-schema HOLD;
- Erysimum: exact-source transport HOLD.

The next search therefore begins with source recoverability rather than biological attractiveness.

## Hard rule

At most five new candidates are screened.

The first candidate that passes every hard source/metadata criterion is admitted. Screening stops there.

If none of the five pass, the replacement search stops. It does not continue indefinitely until a convenient dataset appears.

## Required before admission

A candidate must have:

- at least 20 reported species;
- discrete flower-colour categories documented before row-level data are opened;
- an explicit nested hierarchy, preferably literal white plus at least two non-white fine categories;
- exact trait bytes recoverable now;
- exact branch-length tree bytes recoverable now;
- identity-verifiable source objects;
- a plausible >=20-species trait/tree frame from metadata;
- an author-defined pre-row code map if raw colour is coded rather than literal;
- no CHUN hidden-memory outcome exposure.

Dryad is not considered source-complete merely because a landing page exists. Exact bytes must actually be transportable.

## Allowed screening information

Article methods, sample size, repository file lists, checksums, README, source-code object references, tree tip count/branch-length metadata, and trait headers may be used.

Species-level colour values and colour frequencies may not be opened.

## Stop rule

A source/schema/crosswalk/opportunity/informativeness HOLD may reopen this screen if the search budget remains.

A biological PASS or FAIL ends replacement searching.

If five new candidates all fail source-first admission, stop until a new public dataset is released or a blocked exact source becomes recoverable.

Frozen EL v0.3, Ruellia promotion governance, and Paper 1 are unchanged.
