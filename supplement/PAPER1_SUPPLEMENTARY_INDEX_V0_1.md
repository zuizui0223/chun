# Paper 1 Supplementary Index v0.1

This package materializes sensitivity/provenance tables already frozen in the Paper 1 registries. It does not add new biological analyses.

## Table S1 — Analysis disposition

Current Main, Supplement, provenance-only and excluded analyses, including explicit replacements for superseded headline results.

## Table S2 — Micro sequence-source provenance

Primary article citations, DOI/stable locators, public sequence/run accessions, exact source claim, and project-inference boundary for FLS, DFR, ANS/LDOX and ANR evidence.

## Table S3 — Wild-colour source audit

Accepted species, strict/dominant colour treatment, wild-colour evidence status, source grade, exact species-level locator, citation policy and provenance caveat.

## Table S4 — Primary Camellia pollination evidence

Primary ecological studies supporting the visible-state aliasing and context-dependence discussion, including exact full citation, DOI/stable URL, evidence used, and claim boundary.

## Table S5 — Topology and colour robustness values

Frozen numerical values behind Main Figs 4–5, including split concordance/RF and strict/dominant nearest-same-colour versus global-MPD permutation results.

## Table S6 — Trait-history and identifiability sensitivity

Current root-state sensitivity, zero-shared-event boundary, topology-sensitive global-MPD result, non-strict A-specific result, and the explicit public-data stop rule.

## Supplementary figure plan

The table package is frozen first. Figures will then be built from the same tables without re-fitting models:

- **Fig S1:** accepted-species root-state model sensitivity (W versus Y uncertainty);
- **Fig S2:** state-specific A/W/Y clustering under strict/dominant × FastTree/UFBoot sensitivities;
- **Fig S3:** analytical falsification path from legacy W→A events to accepted-species zero shared robust events.

## Governance

- Excluded/superseded results may appear only in Fig S3 and only as explicitly falsified historical analyses.
- No Supplementary table or figure may upgrade a sensitivity result into a Main headline.
- Public-data provenance and analysis boundaries must remain visible rather than being collapsed into a single 'data source' column.
