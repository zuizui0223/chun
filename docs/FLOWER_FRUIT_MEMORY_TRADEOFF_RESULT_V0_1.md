# Flower–fruit evolutionary-memory trade-off result — v0.1

## Frozen prediction

If reproductive phases specialize in evolutionary lability, stronger flower-color memory was predicted to accompany weaker fruit-color memory, and vice versa.

The test used one identical flower/fruit species frame per clade, iteratively removing states represented by fewer than five tips in either organ, requiring at least 20 retained tips and at least two states in each organ. Flower and fruit memory were then calculated on exactly the same species pairs and the same relative-divergence axis.

## Result: FAIL

Twenty-six clades passed the common cross-organ frame.

Primary signed excess-retention area:

- Spearman rho = **+0.142**
- one-sided permutation P for the preregistered negative direction = **0.75854**
- decision = **FAIL**

The secondary decay-slope comparison was also opposite to the predicted direction:

- rho = **+0.288**
- one-sided P for a negative association = **0.92283**

The primary correlation was negative in **0/26** leave-one-clade-out refits. Flower memory area exceeded fruit memory area in 15 clades, while fruit exceeded flower in 11.

## Biological meaning

This result does **not** contradict the source study's reported negative correlation between the number of flower- and fruit-color transitions. Instead, it shows that two evolutionary summaries need not map onto one another:

1. **transition lability** — how many color changes occur;
2. **relative-time memory** — how strongly same-color state sharing remains concentrated among closer relatives.

The published reproductive-phase trade-off in transition counts therefore cannot be used as the ecological explanation for the CHUN memory-decay heterogeneity.

That is useful narrowing. The temporal-memory result is not simply a repackaging of the flower-versus-fruit specialization reported by the source paper.

## Next causal target

Because simple tree geometry and reproductive-phase specialization both fail to explain the between-clade memory profile, the next defensible ecological moderators are external to the color outcomes themselves. The strongest candidates are **abiotic niche heterogeneity** and **pollinator-regime heterogeneity**, frozen before fitting to the memory slope/area outcomes.

This analysis remains retrospective and does not identify a causal energetic allocation, pollinator, disperser, climate, or pigment mechanism.
