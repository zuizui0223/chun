# Cross-clade mechanistic recurrence benchmark — v0.1

## Aim

The benchmark asks a deliberately narrower question than the atlas as a whole:

> **At what biological level does flower-colour evolution repeat across different comparative systems?**

The answer is not forced into one scalar recurrence rate. The systems below use different inferential units and observation regimes, so pooling their ratios would create a false common denominator.

## Benchmark principle

Repeatability can occur at several levels:

`exact gene / regulator -> pathway module -> functional regulator class -> broad multivariate programme -> visible endpoint`

A high recurrence value at one level does not imply high recurrence at all other levels.

## Current systems

### Ipomoea — exact-gene regulatory recurrence

Three robust independent blue/purple-to-red origins repeatedly implicate reduced floral regulation of F3'H. This is the strongest exact-gene/regulatory positive control in the current benchmark.

### Iochrominae — pathway-module recurrence

Four independent anthocyanin losses show strongly reduced expression of the late anthocyanin module including F3'5'H, DFR and ANS. Specific causal variants are resolved only for a subset, so the cleanest repeatability claim is pathway/module level rather than one exact mutation.

### Aquilegia — late-pathway expression recurrence

Independent anthocyanin losses repeatedly show stronger downregulation toward the end of the pathway. The pattern is convergent at the pathway-expression level without requiring the same causal regulatory variant in every lineage.

### Epimedium — recurrent core with heterogeneous implementation

Four A− endpoint species share ANS downregulation (4/4), while DFR is low in 3/4 and CHS/FLS responses vary. The broadest repeated A− signature is shared by two species; once CHS-copy identity is retained, the complete qualitative implementation is unique to each species in the present panel.

Because historical event identity is unresolved in the relevant Epimedium complexes, this is an endpoint/common-panel benchmark, not an event-recurrence estimate.

### Petunia — regulator-class recurrence without programme recurrence

Two independent colour regains from the colourless long-tube ancestor both restore/recruit R2R3-MYB regulatory function, but they do so differently:

- *P. secreta*: compensatory deletion restores the AN2 reading frame;
- *P. exserta*: AN2 stays nonfunctional; paralog DPL is recruited, together with hydroxylation and acylation changes.

Thus regulator-class recurrence is 2/2 while complete implementation recurrence is 0/2.

### Cape Erica — highly heterogeneous causal nodes

Eight white/yellow derived taxa in the current mechanism table involve five focal node classes (UDP-GST, ANS, F3'H, DFR, bHLH). No exact focal node occurs in more than 2/8 taxa. Six routes are classified as regulatory/expression changes and two as coding losses.

The source comparison sets are putatively independent and are retained as such; the table is a causal-node diversity benchmark, not a pooled event-rate estimate.

### Camellia — transition-class-dependent modular recurrence

Camellia remains the primary matched observation-intervention case:

- anthocyanin gain: candidate-free exact whole-signature recurrence = 1/3; pairwise A/F/C/P concordance = 0.333–0.5;
- yellow development: exact recurrence = 1/2, with A/C/P shared and F differing.

These are not directly comparable numerically with the event-level or candidate-panel systems above. Their role in the benchmark is to show that repeatability changes by transition class even under one frozen state representation.

## Main inference

The cross-clade evidence does **not** support a single global statement such as “flower-colour evolution is highly repeatable” or “flower-colour evolution is mechanistically heterogeneous.”

A more defensible synthesis is:

> **Molecular repeatability is hierarchical, transition dependent, clade dependent, and observation-regime dependent. Some systems repeatedly hit the same regulatory gene, some recur at a pathway module, some share only a regulator class, and others reach similar visible endpoints through highly heterogeneous causal nodes.**

This supports the conceptual architecture of Camellia Paper 1 while explicitly acknowledging that pathway-level convergence and genetic-context effects are established prior art.

## What is not estimated

This benchmark does not calculate:
- a pooled cross-clade recurrence proportion;
- a meta-analytic average of 3/3, 4/4, 2/8, etc.;
- a rank ordering of clades by evolutionary predictability;
- a universal gain-versus-loss asymmetry.

The denominators differ in meaning: robust macro events, endpoint species, developmental systems and dependence clusters are not exchangeable replicates.

## Next empirical use

The benchmark defines the state space for the next atlas phase. For newly admitted clades, record separately:

1. event identity confidence;
2. observation regime;
3. repeated endpoint class;
4. strongest supported recurrence level;
5. whether lower-level implementation remains heterogeneous.

Only systems sharing the same unit and observation regime should later enter a common quantitative estimator.
