# Idea: pigment-network state vector rather than one colour/flux axis

## Origin of the problem

This idea is generated by the quantitative `chun` meta-analysis, not by a literature future-work statement.

The earlier directional synthesis used a deliberately coarse field, `competing_branch_more_active_in_less_red`. Quantitative recovery now shows that this representation collapses distinct biochemical directions that can move independently.

## chun quantitative evidence

### Anthocyanin versus flavonol

Four currently admitted independence clusters are directionally concordant for a relative red-direction anthocyanin-versus-flavonol shift:

- `CSIN_WHITE_PINK`: positive in 5/5 developmental stages;
- `CRETICULATA`: red-white class contrast `+4.5854`;
- `CJAPONICA`: crimson-white contrast `+5.0828`;
- `OIL_CAMELLIA_MULTI`: red-white colour-material contrast `+6.4196`.

This is `4/4` independent quantitative systems. Exact sign `P=0.125`, so it is a concordant preliminary pattern rather than a universal-frequency estimate.

### Proanthocyanidin is separate

`C. sinensis` is developmentally mixed for anthocyanin-minus-PA (`3/5` stages positive), whereas the three other current quantitative systems are positive. In the oil-Camellia material, PA itself increases from W to R while anthocyanin rises more strongly.

Therefore FLS/flavonol and LAR/ANR/PA cannot be merged into one interchangeable `competitor` axis.

### Carotenoid is an independent colour direction

`C. huana` provides an independent within-species colour-variant system. At matched stages:

- `RS1 vs GS1`: 21/22 differential carotenoid metabolites are higher in red-outer-petal material;
- `RS2 vs GS2`: 18/18 are higher in red-outer-petal material.

The source describes carotenoids as the principal colour-forming components in this system. Thus visible red is not synonymous with an anthocyanin-rich biochemical state.

### Visible A still contains large biochemical variation

Fan2026 Table S2 contains 33 quantitative anthocyanin rows while the article describes 29 red-like species. A same-workbook Table S1↔S2 provenance gate currently admits 21 rows as visible A, one as W and leaves 11 unresolved; fuzzy names are not admitted.

Even within the 21 source-crosswalked A rows, total reported anthocyanin spans `24.1` to `596.17`, a **24.7-fold range**. Therefore visible A cannot be treated as one fixed anthocyanin-intensity state even before spectral/pollinator variation is added.

## Primary hypothesis — H_PATHWAY_STATE_VECTOR

A biologically useful Camellia flower-pigment state is a **multidimensional allocation vector**, not a scalar redness or anthocyanin-versus-competitor score.

Minimum current representation:

`P = [anthocyanin, flavonol, proanthocyanidin, carotenoid]`

Each component should ultimately carry:

- deployment/intensity;
- composition;
- node/paralog identity;
- regulatory route.

Visible hue is an observation generated from this biochemical state together with pH, co-pigmentation, cell structure and optical/sensory properties rather than the state itself.

## Consequence for accessibility

`H_ACC` is hierarchical:

1. **node/paralog accessibility** — which specific regulatory or structural loci repeatedly switch;
2. **module accessibility** — which biochemical branch changes net deployment;
3. **vector accessibility** — which combinations of module changes are repeatedly reachable;
4. **phenotype realization** — how the vector maps to chemistry and spectrum.

This matters because broad enzyme families can contain paralogs moving in opposite directions while a smaller functional subset tracks pigment state strongly.

## Consequence for micro-to-macro reuse

`H_MICRO_MACRO_REUSE` should be tested at two resolutions:

- enrichment of high-accessibility nodes/paralogs on independently reconstructed macro transition branches;
- similarity of **module-state-vector displacement** across independent transitions.

A macro transition does not count as reuse merely because any gene in a large pathway family changes.

## Consequence for ecology

Selection-pressure analyses should compare ecology to the latent vector and its sensory projection, not to W/A/Y alone. Different dimensions can have different ecological functions and can be co-activated rather than traded off.

This sharpens `H_SELECTION_TARGET`:

> ecological filtering acts on particular biochemical/spectral vector components or combinations, while human-visible hue is an incomplete observation of those targets.

## Data boundary

Public-data work still comes first:

- recover processed/raw module effects from independent systems;
- validate functional ortholog/paralog mapping;
- quantify within-state biochemical variation;
- construct node/module accessibility scores;
- reconstruct macro transitions on admitted nuclear histories.

New biological measurements become necessary when testing whether the latent vector predicts ecological function better than hue. The missing matched matrix remains standardized pigment chemistry + spectra/UV + reward/phenology + effective pollinator contribution on the same phylogenetic species set.

## Claim boundary

Supported now:

- a single undifferentiated `anthocyanin versus all competitors` scalar is inadequate;
- anthocyanin, flavonol, PA and carotenoid require separable dimensions in the current evidence base;
- visible A/red contains substantial quantitative biochemical heterogeneity.

Not yet supported:

- that four dimensions are sufficient genus-wide;
- that any one vector component is the adaptive target;
- that micro-accessible vector directions are preferentially reused on independent macro branches;
- that a state-vector model predicts pollination or climatic niche better than visible hue before matched ecological measurements are available.
