# Hierarchical evolutionary memory synthesis — v0.3

## Current conclusion

The hierarchical-memory programme now has both a genuine prospective success and a genuine prospective failure.

The strongest defensible conclusion is therefore no longer a universal rule.

> **Fine flower-colour states repeatedly retain lineage history inside broader phenotype classes, but the strength of that hidden history is contingent rather than guaranteed across representations.**

This is a positive evolutionary result, not merely a collection of failed resolution tests.

## Evidence that remains positive

### Standardized visible-colour prevalence

Across the 21 Flower-clades-51 radiations with genuine fine-to-coarse compression opportunity:

- 18/21 have positive permutation-centered hidden-memory effects;
- median centered effect = **+0.0270 AUC**;
- one-sided Wilcoxon **P = 3.34 × 10^-5**;
- one-sided sign test **P = 7.45 × 10^-4**.

The effect is distinct from overall memory amplitude and global coarse-versus-fine tilt.

### Independent external radiations

Linoideae, Angraecinae and Antirrhineae each retain finer phylogenetic organization after conditioning on a broader state, under source-faithful but nonexchangeable estimators.

These are 3 independent supporting radiations, not 3 pooled P-values.

### Prospective visible-colour validation

Schistanthe was admitted and gated before its target colour outcome was opened.

- retained tips = **129**
- centered effect = **+0.06416 AUC**
- one-sided **P = 0.0033**

This is an independent prospective PASS.

### Biochemical evidence is mixed

Petunieae remains strong retrospective same-estimand support:

- retained tips = **47**
- centered effect = **+0.18794 AUC**
- **P = 0.0001**

Gesnerioideae is the first completed prospective biochemical test and it FAILS:

- retained tips = **30**
- centered effect = **−0.00779 AUC**
- **P = 0.5005**

The FAIL is retained exactly as frozen.

## What the Gesnerioideae FAIL means

A post-outcome diagnostic rebuilt the exact frozen permutation null without changing the prospective decision.

Its one-sided alpha = 0.05 critical centered effect is **+0.07199 AUC**.

The independent Schistanthe point effect is **+0.06416 AUC**, which is smaller than that critical effect.

Therefore two statements must be kept separate:

1. **Gesnerioideae prospectively failed its predeclared test.**
2. **That 30-tip test does not strongly exclude effects of the size actually observed in Schistanthe.**

This is not a power analysis and it does not rescue the FAIL. It only defines how strongly the negative result can be interpreted.

## Evolutionary interpretation

The result is now more specific than “flower colour has phylogenetic signal.”

A broad phenotype such as WHITE/NONWHITE or anthocyanin PRESENT/NONE can collapse distinct fine states. In many radiations, those distinctions are not evolutionary noise: they remain non-randomly arranged on the phylogeny after broad-state membership is held fixed.

So the biologically interesting quantity is not one universally optimal phenotype resolution. It is the **amount of lineage history hidden inside a broader phenotype class**.

That hidden history varies among radiations and representations.

This makes hierarchical state-space organization itself an evolutionary axis of variation:

- broad states summarize ecological/display similarity;
- fine states can retain additional lineage-specific history;
- the degree to which that history survives is not constant.

No ecological or molecular cause is inferred yet from this architecture alone.
