## Conservative coding rule

An axis is `unknown` unless the existing evidence product gives a directional mechanistic interpretation. Missing axes are never filled from visible colour.

## Candidate-bias rule

These literature-coded edges are discovery inputs. The intended validation layer re-estimates pathway module states from public petal RNA-seq using a predefined ortholog panel, without selecting genes because the source paper highlighted them.
