# Cross-radiation hierarchical flower-colour rule v0.2

## Current result

The cross-radiation programme now has two distinct empirical conclusions with separate denominators.

### 1. No universal WHITE transition direction

Three external systems have comparable source-to-tree transition-rate reanalyses: Hydrangea sect. Cornidia, Linoideae and Angraecinae.

**0/3** passes a strong common-direction gate.

- Hydrangea point estimates lean coloured -> WHITE, but fixed-tree profile/AIC support is insufficient.
- Linoideae regular UNION point estimates lean WHITE -> nonwhite, but no robust shared directional law is admitted.
- Angraecinae point estimates lean WHITE -> GREEN, but the pre-frozen directional-asymmetry gate fails in both retained tree-reconstruction sets.

Therefore `WHITE ancestry -> one universal transition direction` is not supported.

### 2. Robust WHITE ancestry is not sufficient for direction

Angraecinae remains the direct counterexample. Its primary flower organs retain robust WHITE root support across the retained reconstruction sensitivities (minimum root P(WHITE) = 0.875), while the pre-frozen direction gate fails.

This separates ancestral state from transition direction empirically rather than only conceptually.

### 3. Hierarchical fine-state organization is now replicated in 3/3 testable external radiations

The common conditional-null question has now succeeded in three independent biological systems:

1. **Linoideae — HUE**: hue organization persists after fixing WHITE/nonwhite status. 54/54 correlated sensitivity tests have p=0.0001, observed/null 0.263–0.611.
2. **Angraecinae — FLORAL ORGAN CONFIGURATION**: four-organ state organization persists after fixing primary GREEN/WHITE status. 6/6 retained tree tests have p=0.0001, observed/null 0.513–0.549.
3. **Antirrhineae — PIGMENT CLASS**: anthocyanin versus yellow identity remains organized after fixing pigment presence. The pre-frozen primary gate passes 20/20 posterior-tree tests and the polymorphic sensitivity passes 19/20; observed/null is 0.792–0.863 and 0.828–0.902 respectively.

Posterior trees, source codings and topology reconstructions are uncertainty/sensitivity treatments within a radiation, not additional biological replications.

## Candidate rule

> **Coarse ancestral/display or pigment state constrains the evolutionary state space without fixing a universal transition direction; phylogenetic organization persists at finer hue, floral-organ, or pigment-class levels after conditioning on the coarse state.**

Status: **strongly replicated candidate, 3/3 currently testable external radiations; not yet a universal law.**

## Why this is stronger than the earlier white-ancestor formulation

The repeated result is no longer `white ancestors repeatedly gain colour in one preferred direction`. That formulation fails the comparative transition-rate audit.

Instead, three different fine-state dimensions survive conditioning on their coarse representation:

- hue within visible WHITE/nonwhite;
- organ configuration within GREEN/WHITE;
- pigment chemistry class within pigment presence.

The recurring object is therefore the **hierarchy of the phenotype state space**, not one colour or one direction.

## Next falsification/mechanism gate

Two tasks remain before treating this as a broad evolutionary law:

1. falsify it in at least one additional independent radiation with a genuinely nested state representation;
2. test whether the same hierarchical pattern is mirrored mechanistically — specifically, whether recurrence is stronger at regulatory/pigment modules than at exact genes or genomic implementations.

The second task links the macro pattern to the existing Epimedium and Mimulus molecular layers without claiming that those layers already prove the same mechanism.
