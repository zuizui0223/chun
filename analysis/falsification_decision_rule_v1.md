# Falsification decision rule v1

A candidate counts as a genuine counterexample to the cross-radiation macro flower-colour state-granularity rule only if all of the following hold:

1. **Independent radiation**: the test unit is phylogenetically independent from the already admitted radiations.
2. **Matched phenotype level**: the observation concerns the same flower-colour state axis / state-granularity level, not merely a different molecular endpoint.
3. **Matched observation regime**: the relevant states are observed with sufficiently comparable coverage that missingness cannot explain the mismatch.
4. **Directional incompatibility**: the recovered state-transition pattern is opposite to, or systematically erases, the currently claimed cross-radiation ordering/granularity pattern.
5. **Replicated failure or decisive single radiation**: either the mismatch is replicated across transitions within a radiation, or one radiation is sufficiently complete to make the predicted rule fail decisively.

Classification:
- `REFUTATION`: criteria 1-5 satisfied.
- `ADVERSE_BUT_NOT_REFUTATION`: directionally adverse evidence exists but one or more matched-level criteria fail.
- `HOLD`: evidence is insufficient to adjudicate direction.
- `SUPPORTIVE_ALIGNMENT`: evidence is directionally compatible but not necessarily prospective replication.

Mechanistic non-replication does **not** by itself refute a macro phenotype-level rule.
