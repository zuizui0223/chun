# Hierarchical evolutionary memory synthesis — v0.1

## Central result

The cross-radiation programme no longer needs to be summarized as:

> no universal optimal resolution was found.

A stronger positive synthesis is now available:

> **Evolutionary memory is hierarchical rather than scale-optimal.**

A coarse phenotype can preserve broad historical structure while finer phenotype identity retains additional phylogenetic organization **inside** that coarse state. Because those are nested quantities, one global coarse/intermediate/fine resolution does not have to win universally.

This is the structural explanation for the earlier negative-looking resolution results.

## Evidence tier A — standardized visible-color batch

Using the exact Flower-clades-51 source and the same frozen retained frames, the v0.6 analysis asks:

> among pairs already sharing a coarse color state, does phylogenetic proximity predict sharing the same fine color state?

The null preserves the coarse state and all fine-state counts, permuting fine labels only within coarse groups.

Across 21 clades with genuine fine→coarse representation opportunity:

- **18/21** have positive permutation-centered hidden-memory effects;
- median effect = **+0.0270 AUC**;
- bootstrap 95% interval = **+0.0084 to +0.0453**;
- one-sided Wilcoxon **P = 3.34 × 10^-5**;
- sign test **P = 7.45 × 10^-4**.

This is the strongest standardized within-representation evidence.

It is exploratory and post-outcome, but the effect is not a by-product of coarse membership because that membership is fixed in the permutation null.

## Evidence tier B — biochemical Petunieae under the same logic

The exact audited Petunieae source gives a cross-representation bridge.

On the frozen 47-tip frame:

- coarse anthocyanidin state: 6 absent / 41 present;
- six retained fine compound states;
- observed within-coarse conditional AUC = **0.7018**;
- within-coarse null mean = **0.5139**;
- centered hidden-memory effect = **+0.1879 AUC**;
- 9,999-permutation **P = 0.0001**.

Thus fine biochemical composition remains strongly phylogenetically organized after coarse anthocyanidin presence/absence is fixed.

This is retrospective and comes from the same Petunieae source as the earlier fine-profile result, so it is not a second Petunieae replication. Its value is **cross-representation concordance under the same conceptual estimand**.

## Evidence tier C — three independent external radiations

A separate pre-existing programme already asked the same biological question with source-faithful conditional organization statistics:

- **Linoideae** — hue identity conditional on WHITE/nonwhite;
- **Angraecinae** — floral-organ configuration conditional on GREEN/WHITE;
- **Antirrhineae** — anthocyanin versus yellow pigment identity conditional on pigment presence.

All **3/3** admitted external radiations support conditional fine-state organization.

These analyses use different statistics and uncertainty structures from the Flower-clades conditional AUC. Their P-values are therefore **not pooled** with tiers A or B.

What they provide is independent radiation-level qualitative replication of the same biological architecture.

## Evidence tier D — prospective test remains unopened

The most important remaining gate is *Ruellia*.

Before its row-level HPLC states or CHUN AUCs were opened, the programme froze the prospective prediction:

> if the frozen *Ruellia* frame contains fine→coarse opportunity, exact fine HPLC composition will retain positive within-coarse phylogenetic organization.

PASS requires the pre-frozen conditional AUC to exceed its within-coarse permutation distribution at one-sided P <= 0.05.

That outcome is still unopened because the exact author-used 2023-derived timed tree has not been recovered.

Therefore the new synthesis has a real prospective falsification gate rather than a completed retrospective story only.

## The three coordinates of evolutionary memory

The current architecture separates three biological questions.

### 1. Memory amplitude

How much phenotype history remains at all?

This is the dominant source of between-clade variation in the three-resolution profile and tracks relative-time persistence.

### 2. Global scale tilt

At which representation does the history appear strongest when coarse and fine levels are compared globally?

This is a smaller and largely amplitude-independent axis.

### 3. Hierarchical hidden memory

After coarse state membership is fixed, does fine identity retain additional phylogenetic organization?

The visible batch shows that this quantity is not equivalent to global scale tilt. Five of six globally coarse-tilted opportunity clades still have positive hidden fine memory.

So a global coarse winner does **not** imply that fine historical structure has disappeared.

## Why this resolves the “negative results” problem

The original framing implicitly assumed one dimension:

[
	ext{coarse} quad vs quad 	ext{intermediate} quad vs quad 	ext{fine}.
]

The data now support a nested architecture:

[
oxed{
	ext{evolutionary memory}
=
	ext{amplitude}
+
	ext{global scale tilt}
+
	ext{hidden within-state organization}.
}
]

Under this model, failure of a universal winner is expected rather than disappointing.

The intermediate optimum failed because intermediate curvature is a small component of profile variation.

The absence of a universal fine winner is also expected because fine information can survive **inside** a globally coarse-structured phenotype.

The recurring positive feature is not a winning resolution. It is **hierarchical retention of historical information**.

## Strongest defensible biological statement

> **Flower-color evolution repeatedly preserves nested historical information: finer phenotype identity can remain phylogenetically organized within coarser states across standardized visible-color clades, a biochemical Petunieae hierarchy, and three independent external radiations.**

This statement is stronger than “no universal resolution” but remains bounded:

- tiers are not statistically pooled;
- most evidence is retrospective;
- Petunieae is one biochemical radiation;
- the prospective Ruellia test remains unresolved;
- no common ecological or molecular cause has yet been identified.
