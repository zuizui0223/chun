# Cross-radiation flower-colour state granularity — v0.3

## Current result

The cross-radiation programme now separates three questions that earlier versions partially conflated:

1. **Is there one shared transition direction?** No: 0/3 comparable Mk systems pass a strong directional gate.
2. **Does fine-state phylogenetic organization recur?** Yes: 3/3 independently testable external radiations support it.
3. **Are the preselected biological coarse boundaries privileged constraining layers?** No: exhaustive alternative-partition controls reject that cross-system interpretation.

## Fine-state replication

The independently replicated positive pattern remains:

- Linoideae — hue organization persists after conditioning on WHITE/non-WHITE;
- Angraecinae — four-organ colour configuration remains organized after conditioning on primary GREEN/WHITE;
- Antirrhineae — anthocyanin versus yellow organization remains after conditioning on pigment presence.

These are three independent biological radiations. Tree, coding and posterior-tree sensitivities within a radiation are not counted as replication.

## Specificity correction

The v0.2 wording that a coarse ancestral/display or pigment state *constrains the evolutionary state space* was stronger than the data justify.

Exhaustive bipartition controls show:

- Linoideae: biological WHITE/non-WHITE partition `NOT_ENRICHED`;
- Angraecinae: primary GREEN/WHITE partition `INTERMEDIATE`;
- Antirrhineae: unpigmented/pigmented partition `NOT_ENRICHED`;
- no radiation has an `ENRICHED` biological partition under the pre-frozen rule.

Thus the selected coarse boundaries are useful conditioning variables, but they are not a shared privileged evolutionary layer.

## Revised cross-radiation candidate

> **Flower-colour macroevolution is representation-dependent: fine-state phylogenetic organization recurs across independent radiations, but no tested biological coarse boundary is consistently privileged and coarse coding does not determine a universal transition direction.**

A shorter label is **state-granularity / representation-dependence** rather than a universal coarse-state constraint law.

## What this changes

This is not a retreat to “nothing is general.” The repeated positive object is now clearer:

- the generality is in the persistence of organization at finer phenotype resolution;
- the non-generality is in which coarse partition best summarizes that structure;
- directional-rate conclusions are likewise not universal across the tested radiations.

This makes the state representation itself part of the evolutionary inference problem rather than assuming WHITE/non-WHITE, pigment/no-pigment or another binary coding is biologically canonical.

## Next falsification gate

Two routes are now valid:

1. prospectively specify a new biologically motivated coarse partition and test it in an independent radiation before seeing its partition ranking; or
2. test whether the recurrent fine-state organization aligns with independently resolved molecular pathway/regulatory-module axes.

The second route is especially relevant because the repository already contains mechanistic benchmarks where recurrence ranges from exact-gene reuse to pathway-module or regulator-class reuse.

## Claim boundary

The present evidence does not establish a universal causal law, ecological driver, molecular mechanism, ancestral state or dated transition rate. It establishes a replicated representation-level macroevolutionary pattern and a negative result against privileged coarse-state coding.

Camellia Paper 1 remains unchanged.
