# Separate macro colour-state generation from persistence

## Origin of this problem

This issue is generated by `chun` preliminary results, not by a literature future-work statement.

The molecular and macro analyses now point in different directions:

- molecular/developmental synthesis: regulatory/pathway-flux changes recur in 8/8 independence clusters; red-direction anthocyanin increase recurs in 6/6 informative clusters;
- full Fan 2026 formal-section table: A=25 species in only 4/17 sections versus 9.568 expected under fixed-count label shuffling (P=0.00002; entropy P<0.00001); Y=17 in 4/17 versus 8.045 expected (P=0.00130; entropy P<0.00001);
- A is dominated by one section: 22/25 (88%) in sect. Camellia versus 26.1% expected under the same section-size/state-count null (P<0.00001); Y is 13/17 (76.5%) sect. Chrysantha versus 28.1% expected (P<0.00001); W has no excess one-section dominance;
- visible A/W differences do not mark greater thermal divergence within the two shared section proxies; pollination-function diagnostics also show visible hue is not a deterministic ecological-function state.

The resulting problem is:

> **Does molecular accessibility act mainly on the probability of generating a macroevolutionary colour transition, or are accessible variants generated broadly but filtered at the persistence/loss stage?**

## Why this is distinct from H_FILTER

`ecological filtering` implicitly concerns which variants persist, but the current macro pattern can also arise if gains themselves are lineage-gated, or if one/few old gains radiated. These processes must be separated before calling the pattern adaptive filtering.

## Competing explanations

### G1 — lineage-gated generation

Regulatory/genomic background changes the probability that a molecularly accessible switch becomes a heritable species-level transition.

### G2 — broad generation, differential persistence

Pigment changes arise repeatedly, but only some ecological/genetic backgrounds maintain them long enough to radiate.

### G3 — one/few origins + retention/radiation

The extant concentration is mostly inheritance from a small number of early transitions rather than repeated macro gains.

### G4 — reticulation-assisted spread

Introgression/hybridization transfers state-associated regulatory architecture among lineages.

### G0 — observation-state aliasing

W/A/Y collapses mechanistically distinct states and exaggerates apparent concentration.

## Required analyses after nuclear-tree admission

- [ ] reconstruct W/A/Y and latent pigment-state histories across multiple nuclear trees;
- [ ] estimate gain/redeployment hazard separately from loss/persistence hazard;
- [ ] test gain hazard ~ micro-accessibility score × lineage background;
- [ ] test persistence/loss hazard ~ pollinator/sensory + phenology/reward + validated climate/light + lineage background;
- [ ] compare repeated-gain histories with one/few-origin retention/radiation histories;
- [ ] repeat across reticulation-aware alternatives where nuclear/plastid discordance is strong;
- [ ] only then map micro-labile genes/modules to macro gain events (`H_MICRO_MACRO_REUSE`).

## Reactivation consequence

For an active -> low/suppressed -> active candidate, do not ask only why the second active state was selected. First determine whether:

1. reactivation generation was lineage-gated;
2. reactivation occurred broadly but only persisted under a new ecological regime;
3. the apparent regain is retention/introgression rather than a new transition.

Selection-pressure attribution belongs after the historical event and retention gate.
