# EL v0.7 Ruellia promotion rule — v0.1

## Purpose

Freeze the manuscript-promotion decision **before** the held-out Ruellia HPLC result is available.

Current submission: **Evolution Letters v0.3**.

Candidate under test: **Evolution Letters v0.7 — Flower-color evolutionary memory is hierarchical rather than scale-optimal**.

## Primary promotion gate

Only the pre-frozen **within-coarse hidden-memory** test can unlock scientific promotion of v0.7.

PASS requires all of the following on the frozen Ruellia frame:

1. genuine fine-to-coarse compression opportunity exists;
2. observed within-coarse conditional AUC exceeds the within-coarse permutation mean;
3. one-sided P <= 0.05 under the frozen 9,999 permutations.

A PASS does not automatically replace v0.3. It makes v0.7 scientifically eligible for the normal submission-format/reference/metadata promotion audit.

## FAIL

If opportunity exists but the hidden-memory criterion fails, v0.7 is **not** promoted as a cross-representation hierarchical-memory generalization.

The result must be written into any revised hierarchical candidate. v0.3 remains the current submission.

## Structural zero

If no fine-to-coarse opportunity exists, the system is uninformative for the hidden-memory prediction. It is neither biological success nor failure and cannot unlock promotion.

## HOLD

Source, authoritative-tree, or common-frame HOLD states do not change the science decision. v0.7 remains non-current; v0.3 stays current.

## Independence from the global-tilt prediction

The separate Ruellia global prediction `AUC_fine > AUC_coarse` and the within-coarse hidden-memory prediction answer different questions.

Neither can rescue the other after outcome opening.

For v0.7 promotion, **within-coarse hidden memory is the primary prospective gate**.

## No post-outcome rescue

After the Ruellia result is opened, do not change:

- P threshold;
- fine-state support threshold;
- common frame;
- tree;
- primary contrast;
- promotion criterion.

A failed held-out test can only lead to an explicitly revised later candidate, never an in-place reinterpretation of v0.7.

Frozen EL v0.3 and Camellia Paper 1 remain unchanged.
