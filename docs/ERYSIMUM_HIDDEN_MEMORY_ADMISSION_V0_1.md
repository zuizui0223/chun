## Why this replacement is admissible

Merianieae stopped at a source-schema HOLD before informativeness or hidden-memory AUC was opened. Its frozen replacement rule therefore permits a new metadata-only candidate screen, provided the exposed Merianieae colour codes are not used to rank candidates.

Erysimum is selected from publication/repository metadata only.

The source study reports 40 Erysimum species and defines corolla colour as a discrete three-state trait: yellow, lilac and white. The Dryad deposit provides a named R-code/raw-data package.

## Frozen phenotype hierarchy

yellow, lilac, white.

Frozen coarse state:

If the raw data use numerical or symbolic codes, CHUN may use them only if the exact author package provides an unambiguous code-to-label mapping before species-level colour rows are opened.

If no such pre-row mapping exists, the test stops at HOLD_SCHEMA.
