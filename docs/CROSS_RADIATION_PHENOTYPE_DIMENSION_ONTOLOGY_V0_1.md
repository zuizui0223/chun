# Cross-radiation phenotype-dimension ontology — v0.1

## Why this revision was necessary

The previous tier-expansion result grouped `PIGMENT_AMOUNT_OR_DEPLETION` into one category. That was too broad: continuous pigment quantity, discrete pigment loss, pigment gain, and regain are not interchangeable phenotypes or evolutionary transitions.

An external falsification check also exposed a stronger problem. Fixed anthocyanin-loss transitions can recur at specific floral regulators: wild *Petunia axillaris* carries at least five independently arisen loss-of-function alleles at the R2R3-MYB regulator **AN2**. Wessinger & Rausher (2012) had already synthesized a broader bias toward R2R3-MYB regulatory changes in fixed pigment-loss transitions. Therefore the wording `hue is fine-grained; loss is only coarse/module-level` is rejected.

The superseded claim is:

`HUE_OR_HYDROXYLATION_IS_INTRINSICALLY_FINE_GRAINED_WHILE_PIGMENT_AMOUNT_OR_LOSS_IS_INTRINSICALLY_COARSE_GRAINED`

## New phenotype-dimension ontology

Evidence is now separated into five non-exchangeable dimensions.

### 1. HUE_COMPOSITION

Current admitted systems: Iochrominae, Cape *Erica*, Petunieae, *Ipomoea*, *Penstemon*.

All five currently point to anthocyanin branch-control machinery:

- Iochrominae — F3'H/F3'5'H branching subspace;
- Cape *Erica* — F3'H in both yellow taxa;
- Petunieae — prospectively frozen `BRANCHING_HUE` component passes;
- *Ipomoea* — reduced floral F3'H regulation in 3/3 robust red origins;
- *Penstemon* — 12/13 red-shift cases have independent coding loss of F3'5'H and the remaining case has strongly reduced function.

This is **5/5 descriptive target-class concentration**, not a pooled effect size. Only Petunieae is a prospectively frozen component in this programme.

### 2. PIGMENT_QUANTITY_CONTINUOUS

Only two directly comparable radiation-scale systems are presently admitted:

- Iochrominae — intensity maps to a late-pathway coexpression module;
- Petunieae — the frozen raw amount response has no stable primary subspace; a log-amount sensitivity favors late output but cannot replace the primary result.

This is the largest current information gap. The old analysis gained apparent sample size by mixing continuous quantity with complete pigment loss; that is no longer allowed.

### 3. PIGMENT_LOSS

Current project-admitted controls are heterogeneous:

- Cape *Erica* — white routes span multiple late and regulatory nodes;
- Aquilegia — recurrent late-pathway expression reduction;
- Epimedium — recurrent ANS core with heterogeneous broader implementation;
- *Petunia axillaris* — at least five independently arisen AN2 loss-of-function alleles.

The key correction is that pigment loss is **not inherently low-specificity or unpredictable**. A specific regulator can recur strongly. At the same time, the present admitted systems do not support one universal exact loss target across all clades.

### 4. PIGMENT_GAIN

- Camellia anthocyanin gain — partial multiaxis/module repeatability, no invariant complete programme;
- *Mimulus* luteus group — two parallel gains use distinct but related duplicated MYB loci and coordinated trans-regulatory effects.

This supports regulator/module reuse without requiring identical loci or complete-programme replay.

### 5. REGAIN_FROM_COLORLESS

The Petunia long-tube lineage provides two regains that both restore/recruit R2R3-MYB function but use different molecular solutions. Regulator-class recurrence is 2/2 while complete implementation recurrence is 0/2.

## Revised cross-radiation rule

The retained rule is no longer a monotonic fine-versus-coarse ranking:

> **Phenotype dimension or transition class predicts which molecular target architecture is reused better than a global ranking of flower-colour transitions as more or less mechanistically repeatable.**

For hue/composition, branch-control machinery is currently the strongest repeated target class. For pigment loss, regulator-class and late/core recurrence both occur. Continuous pigment quantity remains underdetermined.

## Relationship to prior art

Transition-type dependence of mutational targets is established prior art. The programme must not claim novelty for that generic principle.

The remaining programme-level candidate is narrower: align a frozen phenotype-dimension ontology with (i) macro state-representation dependence across radiations, (ii) molecular target-class localization, and (iii) prospective tests in unused radiations without changing the ontology after outcomes are seen.

No `first` claim is authorized.

## Next prospective gate

The next prospective test should **not** spend scarce independent data on another hue system: hue/branch-control already has five heterogeneous but concordant controls.

The highest-information unresolved axis is `PIGMENT_QUANTITY_CONTINUOUS`.

Before inspecting outcomes in an unused independent radiation, freeze:

1. the continuous pigment-quantity phenotype definition;
2. admissible molecular target classes;
3. phylogenetic adjustment;
4. PASS/MIXED/FAIL criteria;
5. a no-rescue rule for post-outcome transformations.

A new radiation can then test whether continuous quantity preferentially maps to late-output/global flux regulation or whether the Iochrominae result is clade-specific.

## Claim boundary

Do not infer:

- a universal F3'H or F3'5'H law;
- that all pigment-loss transitions target R2R3-MYBs;
- that hue is intrinsically more repeatable than pigment loss;
- a pooled effect size from heterogeneous event, species, endpoint and within-radiation units;
- event-for-event correspondence between macro and molecular datasets;
- full prospective replication.

Camellia Paper 1 remains unchanged and closed.
