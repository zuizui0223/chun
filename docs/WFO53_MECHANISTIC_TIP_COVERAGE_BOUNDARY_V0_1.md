# WFO53 mechanistic-state tip coverage boundary v0.1

## Question

Can the current *Camellia* public evidence support a mechanistic A/F/C/P ancestral-state or phylogenetic-clustering analysis on the strongest frozen accepted-species nuclear backbone?

## Backbone

Primary accepted-species topology:

- WFO53 IQ-TREE LG+G4 + 1000 UFBoot gene trees -> ASTRAL-IV;
- 53 accepted *Camellia* tips;
- topology artifact from completed run `32552618223`;
- frozen artifact digest `sha256:e9d3a9f88dbbda7b8fa3bbe4d210c5665a2125b289b62639ea51c64614de9ed9`;
- tip list materialized in `data/wfo53_ufboot_accepted_tip_list_v0_1.csv`.

## Current taxon-level mechanistic overlap

The current mechanism/meta-evidence registries contain direct taxon-level pigment or molecular information for many focal systems, but only five of those taxa overlap the 53 accepted tips:

1. *Camellia sinensis*;
2. *C. reticulata*;
3. *C. oleifera*;
4. *C. sasanqua*;
5. *C. chrysanthoides*.

This is **5 / 53 = 9.43%** of the frozen accepted-species topology.

Mechanistically rich systems absent from this backbone include *C. japonica*, *C. nitidissima* and *C. perpetua*.

## Four-axis completeness

More importantly, none of the five overlapping tips currently has a fully defensible taxon-level state on all four primary mechanistic axes:

- A — anthocyanin branch deployment;
- F — flavonol branch deployment;
- C — carotenoid deployment;
- P — proanthocyanidin diversion.

Therefore current complete mechanistic-state coverage is:

**0 / 53 tips**.

The visible colour of an unmeasured tip cannot be used to fill missing mechanistic axes.

## Candidate-free raw-data overlap

Among the five overlapping mechanistic taxa, public raw data already admitted to the candidate-free framework are available for:

- *C. sinensis* — `CF_CS_01`;
- *C. reticulata* — `CF_CR_01`;
- *C. oleifera* — within external dataset `CF_EXT_01`.

Thus immediate standardized raw-data coverage on the frozen nuclear tree is only **3 / 53 tips = 5.66%**, and `CF_EXT_01` remains an external state-representation check rather than a short-timescale training edge.

## Identifiability decision

A mechanistic A/F/C/P phylogenetic transition or clustering analysis on this 53-tip tree is **not currently identifiable**.

The reason is not lack of a public nuclear phylogeny; that problem has been solved at the pattern level. The limiting factor is the mismatch between:

- broad visible-colour taxon coverage on the nuclear tree; and
- sparse, incomplete taxon-level mechanistic pigment-state coverage.

## Consequence for Paper 1

Do not force the micro and macro layers into one common state variable.

Paper 1 should keep two independently identified layers:

### Micro mechanistic layer

Estimate A/F/C/P transitions from within-genotype/developmental/close-lineage systems under the candidate-free standardized observation protocol.

### Macro nuclear layer

Estimate root-independent visible-state phylogenetic pattern from accepted wild-colour taxa on public nuclear topologies.

The gap between these layers is itself reported rather than hidden by hue-to-mechanism imputation.

## Future bridge

A mechanistic macro analysis becomes admissible only when one of the following is achieved:

1. direct biochemical/molecular A/F/C/P evidence is expanded across many additional nuclear-tree tips;
2. a broader public nuclear backbone is reconstructed that includes the current mechanistically rich focal taxa, **and** enough of those taxa have standardized complete mechanistic states;
3. a formally defined latent-state model is developed with measurement-error/partial-observation structure, rather than hard-filling missing axes from visible hue.

Even option 2 alone is insufficient if mechanistic state completeness remains sparse.

## Claim boundary

Current supported claim:

> robust visible-colour phylogenetic structure and short-timescale mechanistic accessibility can both be identified from public data, but their direct taxon-level mechanistic bridge is not yet identified.

Not supported:

- A/F/C/P ancestral-state reconstruction across the 53-tip tree;
- mechanistic branch-transition counts;
- mechanistic-state phylogenetic clustering based on visible hue substitution;
- a claim that the same observed hue corresponds to one biochemical state.
