# Quantitative robustness of the Camellia mechanism meta-analysis

## Purpose

The v0.3 dependence-aware synthesis already showed directional recurrence. This analysis asks a narrower question: **how much inferential weight should be placed on each directional result before common-scale effect sizes are available?**

The unit is the `independence_cluster`, not the paper. A transparent Beta(1,1) posterior is used as an uncertainty summary of the selected evidence base, and an adversarial stress test asks how many entirely opposing independent clusters would be required to erase the current directional signal.

Because the literature is ascertained, none of these posterior probabilities is interpreted as the natural frequency of mechanisms in Camellia evolution.

## Results

### Regulatory/pathway-flux recurrence is the strongest mature meta-level result

Cluster consensus is 10 yes / 0 no.

- exact two-sided sign test: `P = 0.00195312`;
- Beta(1,1) posterior mean recurrence: `0.9167`;
- 95% interval: `0.7151–0.9977`;
- `P(p > 0.75) = 0.9578`;
- three new fully opposing independent clusters would be required before the two-sided sign test exceeds 0.05.

Together with the already-frozen micro-only (9/9), public-raw-only (6/6), scale-stratified and leave-one-cluster-out checks, this is mature enough to retain **short-scale mechanistic accessibility** as a preliminary conclusion. Further raw reanalysis is needed for magnitude and heterogeneity, not to decide whether regulatory/flux lability exists.

### Red-direction anthocyanin recurrence is consistent but less resistant to unseen contradiction

Cluster consensus is 6 yes / 0 no.

- exact sign test: `P = 0.03125`;
- posterior mean: `0.875`;
- 95% interval: `0.5904–0.9964`;
- `P(p > 0.75) = 0.8665`;
- one fully opposing independent cluster would make the exact sign test non-significant.

Therefore the current evidence supports a recurrent direction, but not a claim that the mechanism is nearly universal or that its effect size is large in every lineage.

### Competing-branch reallocation has the same directional robustness as anthocyanin accumulation

The less-red/white/yellow direction has 6 yes / 0 no interpretable cluster consensus for competing-branch deployment.

This supports repeated flux partitioning away from anthocyanin-like deployment, but common DFR/ANS versus FLS/ANR/LAR module scores are still required to estimate the magnitude and between-system heterogeneity.

### Downstream anthocyanin activation remains directional but underpowered

The current 4/4 pattern has `P = 0.125` and a wide Beta(1,1) interval (`0.478–0.995`). It should remain supporting mechanistic evidence, not a standalone statistically mature meta conclusion.

### Structural-gene loss frequency is still unidentified

Only three independence clusters directly test whether structural loss is required, and all three say no. This demonstrates that structural loss is **not necessary** for important Camellia colour contrasts. It does not estimate how rare gene loss is genus-wide because seven of ten clusters do not directly test coding-sequence loss.

## Connection to the main programme

This analysis sharpens the cross-scale logic:

1. **generation potential:** regulatory/flux accessibility is the strongest mature micro-level conclusion;
2. **direction:** redder states repeatedly show greater anthocyanin deployment, but effect magnitude still needs harmonization;
3. **macro realization:** current section concentration cannot tell whether the bottleneck is gain, persistence/loss, radiation or reticulation;
4. **selection target:** visible hue is too compressed to distinguish the ecological filters acting after generation.

The next meta-analysis gain is therefore not more vote counting. It is **common-scale effect-size recovery** from public processed tables and, where needed, admitted raw RNA-seq/metabolome data.
