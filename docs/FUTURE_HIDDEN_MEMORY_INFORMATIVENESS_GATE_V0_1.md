# Future prospective hidden-memory informativeness gate — v0.1

## Why this gate now exists

The first completed prospective biochemical hidden-memory test, Gesnerioideae, correctly returned FAIL under its frozen rule.

A later diagnostic showed that its exact one-sided alpha = 0.05 centered critical effect was **+0.07199 AUC**. The independently observed prospective Schistanthe effect was **+0.06416 AUC**.

So even a point effect as large as Schistanthe's would not have crossed the Gesnerioideae null threshold.

That does not change the Gesnerioideae FAIL. It does show that future tests need a separate pre-AUC information check if a negative result is going to be interpreted as informative about effects of the magnitude already observed prospectively.

## Future-only rule

This rule applies only to hidden-memory systems that have **not yet been frozen** when this gate is adopted.

It does not apply retroactively to Gesnerioideae, Ruellia, Schistanthe, Ng2018 or Petunieae.

It does not modify the Ruellia-specific promotion rule.

## Sequence

Before opening the observed conditional AUC in a new eligible system:

1. freeze the candidate-specific representation, source/tree rules, support thresholds, estimator, null and PASS criterion;
2. freeze the identifier crosswalk;
3. open the permitted state-support layer and confirm fine-to-coarse compression opportunity;
4. construct the same-coarse pair universe and negative-patristic-distance ranks;
5. generate 9,999 within-coarse fine-label permutations using seed 20260927;
6. calculate the permutation-null mean and one-sided 5% critical AUC;
7. center the critical AUC on the null mean.

Benchmark:

**+0.0641579911 AUC**, the independently observed Schistanthe prospective centered effect.

### Informative gate

If centered critical effect <= +0.0641579911, then:

PRE_AUC_INFORMATION_GATE_PASS_OPEN_OBSERVED_AUC

and the observed AUC may be opened.

If centered critical effect > +0.0641579911, then stop at:

STRUCTURAL_LOW_INFORMATION_HOLD_OBSERVED_AUC_UNOPENED

This HOLD is not a biological failure.

## What this does and does not mean

This is **not a power analysis**. It does not specify an alternative-effect distribution and does not estimate detection probability.

It asks only whether a point effect equal to the Schistanthe observed effect lies beyond the design's own frozen one-sided null critical threshold.

Passing the gate does not guarantee a PASS.

Failing the gate does not support absence of hidden memory.

The purpose is narrower: do not spend another prospective system on a negative result whose null geometry is too coarse to adjudicate an already observed benchmark-sized point effect.

## Scientific consequence

The programme now distinguishes three gates:

- **opportunity** — do finer states actually exist inside coarse states?
- **informativeness** — can the frozen null distinguish a Schistanthe-sized point effect at the predeclared alpha?
- **realization** — after those structural gates pass, does the observed fine-state arrangement actually carry excess phylogenetic memory?

That separation is future-facing only. Previous outcomes remain exactly as originally classified.
