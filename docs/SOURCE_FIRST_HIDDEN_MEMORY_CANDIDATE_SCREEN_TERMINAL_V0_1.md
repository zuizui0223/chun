## Why the search stops

The search strategy was frozen before candidates 1–5 were evaluated:

- maximum five new candidates;
- discovery order;
- stop at the first complete candidate;
- if none pass, stop open-ended candidate searching.

All five failed before a biological hidden-memory outcome was opened.

Therefore CHUN does not add candidate #6.
