# Camellia pollination-function meta diagnostic v0.2

## Why this analysis follows the climate null

The molecular synthesis shows highly recurrent pigment-network accessibility, whereas the direct and history-proxy climate analyses do not show a general visible A/W -> thermal niche divergence relationship.

The next question is therefore not simply whether pollinators differ among Camellia species. It is:

> Does coarse visible hue represent the reproductive/sensory state on which ecological filtering could act?

This diagnostic uses primary pollination studies only where a broad effective/functional pollinator class can be defended. Study designs remain heterogeneous, so this is not a conventional effect-size meta-analysis.

## Primary-evidence seed

Seven taxa are currently admitted:

- Y: *C. petelotii*, *C. pubipetala*, *C. perpetua*;
- A: *C. japonica*, *C. rusticana*;
- W: *C. oleifera*, *C. sinensis*.

Broad pollinator functions:

- bird-dominant = 3;
- insect-dominant = 3;
- mixed/context-dependent = 1.

The source designs include bird exclusion, hand-pollination, seasonal field comparison, bird-mediated pollen flow, behavioral choice + spectra, single-visit pollen-transfer efficiency, and field insect-pollination observations.

## Result 1 — visible hue is not a deterministic reproductive state

Among visible states with at least two admitted taxa:

- A: bird-dominant + insect-dominant;
- Y: bird-dominant + mixed/context-dependent;
- W: insect-dominant + insect-dominant in the current two-taxon seed.

Thus 2/3 multi-taxon visible states contain more than one broad pollinator-functional class.

The strongest exact collision is within A/red: *C. japonica* is bird-dominant while *C. rusticana* is insect-dominant, despite both occupying the same coarse visible state. Their paired spectral study additionally resolves different UV/fluorescence strategies.

This supports `H_STATE_ALIASING` and increases the priority of `H_SELECTION_TARGET`: visible W/A/Y is an observation layer, while the ecologically selected phenotype may lie in spectral/UV, pigment chemistry, floral geometry, reward and phenology space.

## Result 2 — the small current seed cannot estimate a hue-pollinator association

With hue counts A=2, W=2, Y=3 and pollinator-function totals bird=3, insect=3, mixed=1:

- observed mutual information = **0.53341 nats**;
- exact unique pollinator-label assignments preserving class totals = 140;
- exact upper-tail association P = **0.48571**.

This must not be read as evidence that hue and pollination are independent. The sample is small and strongly literature-ascertained. It means the present evidence cannot support a genus-level categorical `visible hue -> pollinator guild` model.

## Result 3 — reproductive niche can change while visible hue does not

Four admitted primary-evidence taxa contain explicit environment/season-linked modulation of pollinator availability, weighting or pollen-flow context without a visible-hue change:

- *C. petelotii*: honeybee visitation declines in cloudy/rainy weather;
- *C. perpetua*: bird visitation and reproductive contribution are stronger in winter than summer;
- *C. japonica*: volcanic disturbance changes bird movement/pollen-flow structure;
- *C. sinensis*: bee contribution is seasonal within an insect-pollinated system.

These effects are not commensurable and are not counted as a biological support frequency. Their synthesis establishes a narrower point:

> reproductive/pollination niche is dynamically modulated by ecological context even while coarse visible hue is unchanged.

Therefore the converse assumption — that a visible hue change necessarily marks a reproductive-niche change — is also unsafe.

## Connection to the molecular meta-analysis

The current cross-scale pattern is now:

1. **generation:** pigment-network deployment is repeatedly easy to alter (`H_ACC`);
2. **visible observation:** W/A/Y compresses several molecular and sensory states (`H_STATE_ALIASING`);
3. **climate:** visible A/W divergence does not robustly identify thermal niche divergence (`H_VISIBLE_HUE_MACRO_NULL`);
4. **pollination:** reproductive function can differ within the same visible hue and can vary through time/environment without hue change;
5. **macro persistence:** A is nevertheless strongly concentrated in a small number of historical-section proxies (`H_LINEAGE_PERMISSIVITY`).

This combination argues against both simple chains:

`pigment access -> red hue -> cold niche`

and

`pigment access -> visible hue -> fixed pollinator syndrome`.

The more defensible working model is:

`molecular accessibility -> latent biochemical/spectral/reward phenotype -> context-dependent reproductive + abiotic filtering -> lineage-specific persistence`.

## Hypothesis consequences

### Strengthened

- `H_STATE_ALIASING` — visible hue is demonstrably many-to-one with ecological function.
- `H_SELECTION_TARGET` — selection should be tested on latent pigment/spectral/reward/phenology states rather than hue alone.
- `H_LINEAGE_PERMISSIVITY` — because neither climate nor hue-defined pollinator class trivially explains macro persistence, historical/genetic background remains a major interaction term.

### Raised in priority but not demonstrated

- `H_REPRODUCTIVE_NICHE` — flower-colour evolution may often accompany reproductive/sensory-niche turnover rather than abiotic niche innovation.
- `H_CLIMATE_POLL_MED` — climate/season may influence floral selection indirectly by altering pollinator reliability/availability.

### Still unresolved

- whether reproductive/sensory shifts occur on the same nuclear branches as pigment transitions;
- whether those shifts precede, follow or coincide with pigment reactivation;
- whether latent spectral/pigment state predicts pollination better than visible hue out of sample;
- whether reproductive-niche shifts improve lineage persistence/diversification.

## Next decisive analysis

The branch-level target remains:

1. reconstruct pigment/latent-state transition probabilities on primary nuclear trees;
2. reconstruct pollinator/sensory and validated climatic events on the same branches;
3. compare standardized event alignment for reproductive versus climatic niche shifts;
4. test `pollinator first`, `climate -> pollinator -> pigment`, `pigment first`, synchronous and independent histories.

Until a machine-readable primary nuclear tree is admitted, the current analyses are screening evidence rather than causal event reconstruction.
