# Cape Erica phenotype-axis to molecular-subspace bridge v0.1

## Result

The existing eight-derived-taxon mechanism table separates into two visible phenotype axes:

- **WHITE / pigment depletion**: 6 taxa;
- **YELLOW / hue branch**: 2 taxa.

Their focal molecular-node distributions differ sharply.

### WHITE / pigment depletion

The six white taxa use four focal-node classes:

- `UDP_GST`;
- `ANS`;
- `DFR`;
- `bHLH`.

No white taxon in this table has `F3_PRIME_H` as the focal node (`0/6`). No focal node occurs in more than two white taxa.

### YELLOW / hue branch

Both yellow taxa have the same focal node, `F3_PRIME_H` (`2/2`), at the `BRANCH_HYDROXYLATION` level. The lower-level implementation still differs:

- one regulatory/expression route;
- one coding-loss route.

Thus the same-radiation result is:

`HUE_BRANCH_CONCENTRATES_ON_F3_PRIME_H_WHILE_PIGMENT_DEPLETION_DISPERSES_ACROSS_LATE_AND_REGULATORY_NODES`

## Relation to Iochrominae

This is retrospectively compatible with the Iochrominae cross-level bridge: a hue-related phenotype axis maps to a branching-enzyme subspace, whereas pigment presence/depletion engages a different and broader molecular region.

It is **not** a prospective validation. The Erica table existed and had already been inspected before this bridge definition was formalized. Therefore the status is:

`RETROSPECTIVE_INDEPENDENT_ALIGNMENT_AT_PHENOTYPE_AXIS_TO_MOLECULAR_SUBSPACE_LEVEL`

## Boundaries

The source comparison sets remain putatively independent and are not used as a common event-rate denominator. This analysis does not estimate a pooled recurrence probability, exact mutation recurrence, ancestral direction, or ecological cause.

Paper 1 remains unchanged.
