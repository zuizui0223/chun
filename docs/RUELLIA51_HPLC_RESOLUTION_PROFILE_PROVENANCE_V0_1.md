# Ruellia 51-species profile provenance v0.1

The representation was frozen using publication-level source description and author-code schema only. Article DOI: `10.1002/ajb2.70149`. Public data DOI: `10.6084/m9.figshare.30282448`. Public code repository commit inspected for schema: `38bb511da1390bdd525a15ea8738bcc3f016fb59`.
