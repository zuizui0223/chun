## Current state

The project now has three inferential layers that must remain separate.

### 1. Replicated macro state-granularity pattern

Across Linoideae, Angraecinae and Antirrhineae, fine-state phylogenetic organization is supported in 3/3 independent external radiations. A universal transition direction is not supported, and exhaustive partition controls reject one shared privileged coarse boundary.

### 2. Matched high-level cross-level alignment

Two independent radiations now show the same **high-level** phenotype-axis-to-molecular-subspace pattern.

- **Iochrominae**: pigment presence/intensity and anthocyanidin hue map to different molecular subspaces.
- **Cape Erica**: yellow/hue-branch taxa concentrate on `F3'H`, while white/pigment-depletion taxa disperse across late structural and regulatory nodes.

This is `RETROSPECTIVE_ALIGNMENT_IN_TWO_INDEPENDENT_RADIATIONS`.

It is not prospective replication: the source studies and Erica mechanism table were already available/inspected before the common cross-level definition was frozen.

Epimedium independently shows that a shared source-level visible endpoint can retain a recurrent molecular core while lower-level implementation diverges. This is compatible with the same broad state-resolution logic but uses a different bridge definition and unresolved historical event identity.
