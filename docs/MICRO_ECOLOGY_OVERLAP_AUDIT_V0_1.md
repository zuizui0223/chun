# Micro–ecology overlap audit v0.1

## Question

Paper 1 has five candidate-free A/F/C/P molecular systems and a separate Camellia pollination/ecology evidence layer. Several taxa occur in both layers. The critical question is whether that overlap is merely taxonomic or whether the molecular and ecological measurements describe the **same contrast/event**.

The audit therefore distinguishes:

1. taxon-name overlap;
2. matched biological contrast / measurement unit;
3. same study or sample set;
4. an identifiable molecular–ecological event bridge.

## Result

The five frozen candidate-free systems are:

- `CJAPONICA` — *C. japonica*, Joy Kendrick pink vs red petal regions;
- `CRETICULATA` — *C. reticulata*, Manao white vs red petal regions;
- `CSIN_WHITE_PINK` — *C. sinensis*, matched white vs pink developmental series;
- `CNITIDISSIMA` — *C. nitidissima*, S1–S5 yellow-flower development;
- `CPERPETUA` — *C. perpetua*, S1–S5 yellow-flower development.

Three taxa also occur in the admitted pollination-function table:

- *C. japonica*;
- *C. sinensis*;
- *C. perpetua*.

Thus naive taxon-name overlap is **3/5 = 60%**.

However, none uses the same molecular/ecological contrast:

- *C. japonica*: cultivar petal-region pink/red RNA-seq versus wild-species bird-service / spectral-behaviour evidence;
- *C. sinensis*: white/pink developmental material versus seed-garden insect-pollination context;
- *C. perpetua*: S1–S5 developmental molecular trajectory versus winter/summer reward–pollinator–fitness ecology.

Therefore:

- contrast-matched systems = **0/5**;
- same-study/sample systems = **0/5**;
- event-matched molecular→ecological systems = **0/5**.

## Interpretation

The public evidence has much more cross-layer **taxonomic overlap** than cross-layer **causal identifiability**. Treating the three overlapping taxa as three micro-to-ecology replications would be pseudoreplication across incompatible contrasts.

This sharpens the Paper 1 boundary:

> Molecular repeatability and pollinator-mediated filtering can each be supported at their own evidence scale, but the present public data do not identify whether a particular candidate-free A/F/C/P implementation caused or predicted ecological function in the same event.

This is not a failure of the ecological-filter hypothesis. It explains why the current paper must separate `generation` from `filtering/persistence` rather than connecting them with an unobserved mechanistic arrow.

## Highest-value closure targets

### 1. *Camellia japonica* — best mechanistic/sensory closure target

It already has:

- candidate-free A/F/C/P data;
- strong bird-service evidence;
- paired UV/fluorescence/bee-choice evidence.

The missing bridge is **matched wild floral material** carrying pigment chemistry / A/F/C/P or equivalent molecular state, quantitative spectra, pollinator effectiveness and reproductive fitness in the same contrast.

### 2. *Camellia perpetua* — best flowering-window closure target

It already has:

- candidate-free S1–S5 developmental A/F/C/P trajectory;
- a strong same-study winter/summer `season -> nectar -> bird visitation -> fruit/seed success` bridge.

The missing test is to measure petal molecular/spectral state in those same winter/summer populations or samples. This would directly test whether flowering-window ecological filtering is accompanied by a change in the latent floral state rather than importing an unrelated developmental series.

### 3. *Camellia sinensis* — lower-priority closure target

Molecular white/pink developmental contrasts and seed-garden pollination evidence both exist, but the cultivated contexts are poorly aligned. A new matched design would be required before causal interpretation.

## Consequence

The next efficient step is **not** another broad annual-climate analysis or another unpaired molecular dataset. It is to close one matched molecular/sensory/ecological contrast, preferably in *C. japonica* or *C. perpetua*.

## Claim ceiling

This is an identifiability and overlap audit. The 3/5 taxon overlap is descriptive and must not be written as evidence for three causal micro-to-ecology replications. Event-compatible overlap is currently zero.
