# Schistanthe prospective support boundary — v0.1

The prospective Schistanthe hidden-memory PASS is an independent validation of the hierarchical-memory model, but it does **not** replace or modify the already-frozen Ruellia-specific EL v0.7 promotion rule.

Reason:

- the v0.7 promotion gate was frozen before the Ruellia result and explicitly names the held-out biochemical Ruellia test;
- changing that gate after a favorable Schistanthe result would be post-outcome substitution;
- Schistanthe is a visible-color radiation, whereas Ruellia is the pre-frozen cross-representation biochemical falsification.

Therefore:

- Schistanthe PASS may be added to the hierarchical-memory evidence synthesis;
- it may motivate a later v0.8 candidate;
- it may not by itself promote v0.7 over current EL v0.3.

This preserves the prospective logic rather than using a favorable new system to rewrite the decision rule.
