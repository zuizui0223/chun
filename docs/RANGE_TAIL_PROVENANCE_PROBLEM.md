# Range-tail provenance before macroevolutionary boundary inference

## Current position

A robustness failure in the 50-species GBIF × CHELSA analysis initially suggested a potentially interesting biological pattern: the very cold BIO6 q05 values of sect. Tuberculatae appeared to dominate a traditional-section effect on the cold edge.

Direct recovery of the GitHub Actions artifact changed that interpretation.

> **The apparent Tuberculatae cold-edge innovation is generated by a tiny number of out-of-range GBIF records, not by a robust concentration of cold occurrences.**

This creates a new upstream problem for the whole macroevolutionary programme:

> **Before asking whether a flower-colour/pigment state enabled a lineage to cross an environmental boundary, how do we prove that the inferred occurrence-derived boundary is a biological range edge rather than a provenance/georeferencing/taxonomic artefact?**

## 1. What generated the false biological candidate

The original exact 50-species table contained:

- *Camellia rhytidocarpa*: `n=18`, BIO6 q05 `-14.105 C`;
- *C. tuberculata*: `n=12`, BIO6 q05 `-16.415 C`.

Those two white taxa made the initial A/W-only traditional-section model for BIO6 q05 look strong (`R2=0.44236`, `P=0.00196`). Removing the entire Tuberculatae section had already destroyed that result.

The Actions artifact `thermal_points.csv` reveals that both species contain the same two extreme coordinates:

| taxon | GBIF key | basis | latitude | longitude | BIO6 |
|---|---:|---|---:|---:|---:|
| *C. rhytidocarpa* | 4044189601 | preserved specimen | 42.900000 | 125.140000 | -20.65 C |
| *C. rhytidocarpa* | 2250665548 | material sample | 38.073254 | 104.691140 | -12.95 C |
| *C. tuberculata* | 4043637661 | preserved specimen | 42.900000 | 125.140000 | -20.65 C |
| *C. tuberculata* | 2250664859 | material sample | 38.073254 | 104.691140 | -12.95 C |

The two taxa also share a third, non-extreme coordinate at 28.58 N, 105.70 E. Exact cross-taxon coordinate reuse is therefore itself a useful provenance warning for narrow-ranged taxa.

## 2. Why the two extreme coordinates fail the range plausibility gate

A peer-reviewed Sect. Tuberculata distribution analysis, after combining and cleaning records from CVH, GBIF, POWO and field surveys, places the section primarily within approximately `22.54–30.96 N, 103.83–111.76 E`.

Current POWO native ranges are also geographically restricted:

- *C. rhytidocarpa*: NE Guangxi, SE Guizhou, SW Hunan;
- *C. tuberculata*: S Sichuan, N Guizhou.

Thus `42.90 N, 125.14 E` and `38.07 N, 104.69 E` are not plausible representatives of the accepted native distributions used to infer a biological cold edge.

The project does not need to know the exact database failure mode before excluding these records from the biological edge claim. Possibilities include historical misidentification, duplicated/georeferenced locality, metadata association error or taxonomic remapping. The critical point is that they fail an independent native-range plausibility gate.

## 3. Minimal correction: remove only the two shared extreme coordinates

This is deliberately conservative: no broad polygon clipping is imposed on all records. Only the two exact shared coordinates that are grossly outside the independent range evidence are removed from the two focal taxa.

Species-level effect:

- *C. rhytidocarpa*: `n 18 -> 16`, BIO6 q05 `-14.105 -> +1.425 C` (`+15.53 C`);
- *C. tuberculata*: `n 12 -> 10`, BIO6 q05 `-16.415 -> +0.400 C` (`+16.815 C`).

A/W-only cold-tail model after correction:

- visible A/W state: `R2=0.02837`, `P=0.25248`, AIC `278.62`;
- traditional section: `R2=0.23511`, `P=0.18937`, AIC `281.13`;
- null: AIC `278.00`.

The null model is preferred. The earlier section result disappears.

The corrected A-W permutation test remains non-significant:

- mean A BIO6 q05 = `-2.864 C`;
- mean W BIO6 q05 = `-1.274 C`;
- A-W = `-1.589 C`;
- two-sided permutation `P=0.25186`.

So cleaning the false extreme does **not** resurrect a genus-wide red/cold relationship.

## 4. Stricter sensitivity reaches the same answer

As a secondary sensitivity only, the two focal Tuberculatae taxa were restricted to the peer-reviewed section-level envelope `22.54–30.96 N, 103.83–111.76 E`.

Result:

- *C. rhytidocarpa*: `n=15`, BIO6 q05 `+1.42 C`;
- *C. tuberculata*: `n=5`, BIO6 q05 `+0.21 C`;
- A/W-only section model: `R2=0.23418`, `P=0.19213`;
- A/W cold-tail permutation: `P=0.253997`.

This stricter screen agrees with the minimal correction. It is not promoted to the primary filter because a section-wide rectangular envelope is cruder than taxon-specific polygons/provenance.

## 5. New problem generated by the failure

### H_EDGE_EPISODIC — current Tuberculatae case rejected

The current Tuberculatae signal does **not** support a biological rare cold-edge shift. Its extreme q05 values are provenance-sensitive and collapse after removal of four record instances representing two implausible shared coordinates.

This does not reject the general possibility that true rare branch-specific edge shifts exist elsewhere in *Camellia*. It rejects this particular candidate as evidence for them.

### H_TAIL_PROVENANCE — occurrence provenance can dominate tail-based niche inference

Supported case-level prediction:

> For sparsely sampled/narrow-ranged taxa, a few out-of-range records can move q05-derived climatic boundaries by an order of magnitude larger than the between-state effects being tested.

Here two records per taxon moved BIO6 q05 by `15.53–16.82 C`.

### H_BOUNDARY_VALIDATION — range-edge events require a stronger admission gate than niche centroids

A branch may be called a climatic boundary-crossing event only after its edge records pass, at minimum:

1. accepted taxon/name check;
2. specimen/occurrence provenance retention;
3. independent native-range plausibility;
4. cross-taxon coordinate-reuse audit;
5. leave-one-record-out / leave-one-locality-out leverage test;
6. support by multiple independent localities or collections;
7. sensitivity to q05 versus more robust lower-tail estimators.

A country-only native filter is insufficient for narrow endemic species.

## 6. Pipeline change

`scripts/audit_gbif_tail_provenance.py` now audits the K coldest records per taxon and records:

- GBIF key and coordinates;
- leave-one-record-out q05 change;
- exact coordinate reuse across taxa;
- current GBIF scientific/accepted names and taxon keys;
- dataset, institution, catalogue/occurrence ID;
- identifier/identification qualifiers;
- coordinate uncertainty;
- state/province/locality/event date and georeferencing metadata.

The Fan2026 GBIF × CHELSA workflow now runs this provenance audit before its artifact is admitted for biological range-edge interpretation.

## 7. Consequence for the broader flower-colour question

The revised hierarchy is now:

`occurrence provenance -> validated climatic boundary -> latent pigment/sensory state -> nuclear branch history -> ecological filtering`

This matters because a causal lead/lag analysis can otherwise become extremely precise about the temporal relationship between a pigment transition and a **false environmental event**.

The failure therefore improves the main project rather than merely deleting an outlier: it defines a new admission gate for every future niche-boundary claim.

## 8. Claim boundary

Supported now:

> The original Tuberculatae extreme cold-tail result is artefact-sensitive and should not be interpreted as a biological cold-edge innovation. A country-only GBIF filter is insufficient for tail-based inference in narrow-ranged Camellia, and record-level provenance/range validation is required upstream of macroevolutionary boundary modelling.

Not yet supported:

- the exact historical reason each GBIF record received its coordinate/taxon association;
- that all remaining Tuberculatae occurrence points are error-free;
- that q05 is unusable once a provenance gate is applied;
- that rare true boundary shifts do not occur elsewhere in the genus.
