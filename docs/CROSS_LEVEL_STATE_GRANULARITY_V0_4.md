# Cross-level flower-colour state granularity v0.4

## Current result

The macroevolutionary result is now well separated from the molecular evidence level.

### Macro layer

Across the three independent external radiations with comparable fine-state tests:

- fine-state phylogenetic organization: **3/3 supported**;
- strong common transition direction: **0/3**;
- shared privileged biological coarse partition: **not supported**.

The retained macro inference is therefore representation dependence / state granularity, not a white-ancestry direction law or one privileged colour boundary.

### Same-radiation cross-level compatibility

Two independent radiations now connect visible representation to molecular resolution, but they do **not** instantiate the same estimator.

#### Iochrominae

Within one 28-species radiation:

- anthocyanin presence/intensity maps to a late-pathway coexpression module;
- anthocyanidin hue maps to a branching-gene subspace;
- early pathway expression remains comparatively conserved.

This is a `PHENOTYPE_DIMENSION_TO_MOLECULAR_SUBSPACE` bridge.

#### Epimedium sect. Diphyllon

Six taxa overlap between the source-audited reproductive table and the common molecular panel. The three overlapping A− taxa share the same source joint organ code (`1:1`) and a recurrent ANS-low core, while DFR and CHS implementation separate at finer resolution.

This is a `VISIBLE_ENDPOINT_TO_HIERARCHICAL_MOLECULAR_IMPLEMENTATION` bridge. Historical event identity remains unresolved.

## What can now be said

> Visible flower-colour representations can hide molecularly distinct subspaces or implementations within the same radiation.

This statement is supported by two complementary same-radiation cases.

## What cannot yet be said

The two bridges are not the same test. Therefore:

- no pooled molecular recurrence proportion is calculated;
- no `2/2 mechanistic replication` claim is made;
- no universal phenotype-to-gene mapping is inferred;
- no common event-level transition mechanism is inferred;
- no ecological causal law follows.

The mechanistic status is:

`COMPATIBILITY_SUPPORTED_NOT_REPLICATED_COMMON_LAW`
