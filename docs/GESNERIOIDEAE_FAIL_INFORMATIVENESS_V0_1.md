# Gesnerioideae prospective FAIL — informativeness audit v0.1

## Result

The prospective biochemical decision remains exactly:

**PROSPECTIVE_GESNERIOIDEAE_BIOCHEMICAL_HIDDEN_MEMORY_FAIL**

No threshold, state coding, common frame, tree, permutation scheme, or promotion rule is changed.

A post-outcome diagnostic rebuilt the exact frozen 9,999-permutation null and asked a narrower question:

> How large would the observed centered conditional-AUC effect have needed to be to cross the frozen one-sided alpha = 0.05 threshold in this 30-tip design?

The answer is:

- null mean AUC = **0.61445**
- one-sided 5% critical AUC = **0.68643**
- critical centered effect = **+0.07199 AUC**
- observed centered effect = **-0.00779 AUC**

For comparison, the independent prospective Schistanthe PASS had centered effect **+0.06416 AUC**.

Thus a point effect equal to the observed Schistanthe effect would still fall about **0.00783 AUC below** the Gesnerioideae critical threshold.

## Interpretation

This changes the *strength of interpretation*, not the decision.

Gesnerioideae is a valid prospective FAIL under the pre-frozen rule. But it is **not a high-resolution falsification of Schistanthe-sized hierarchical memory**: the frozen 30-tip design would require a somewhat larger point effect than Schistanthe actually produced before crossing its one-sided significance threshold.

Therefore the current prospective evidence is asymmetric:

- **Schistanthe:** positive, independently prospective visible-color evidence;
- **Gesnerioideae:** prospective biochemical FAIL, but with a critical effect larger than the Schistanthe point effect;
- **Petunieae:** strong biochemical support, but retrospective;
- **Ng2018:** source/schema HOLD, no biological outcome;
- **Ruellia:** still outcome-unopened because authoritative tree provenance remains unresolved.

The appropriate synthesis is not “biochemical hierarchy is disproven.” It is:

> Prospective visible-color hierarchical memory is supported; biochemical generalization remains unresolved because the first completed prospective biochemical test failed in a relatively low-resolution 30-tip frame.

## Boundary

This is **not a power analysis**. It does not estimate an alternative distribution or probability of detection.

It is an exact null-threshold diagnostic using the already-frozen Gesnerioideae design and permutations. It cannot rescue the FAIL or reopen EL v0.9 promotion.
