# Ruellia51 exact-tree source recovery v0.1

## Result

`TREE_NOT_PRESENT_IN_ANY_FIGSHARE_VERSION_OUTCOMES_UNOPENED`

The Figshare version history for article `30282448` was inspected using metadata only after the Ruellia profile and source gates were frozen.

- v1 contains only `anthocyanins_spectra.csv` and `raw_data.csv`.
- v2 contains the same two files plus `ruellia_occurrences.csv`.
- neither version contains `03-Ruellia_phylo.timed.tre` or any other tree file.

Thus the timed tree was not removed during the v1 -> v2 update; it was never deposited in this Figshare article version history.

A 2023 New World *Ruellia* study (`10.1002/tax.13001`) reports a ddRAD phylogeny for 187 species, but source discovery has not demonstrated that any public tree object from that study is byte-identical or analytically identical to the exact timed tree read by the Watts et al. author code. CHUN therefore does not substitute it.

The terminal gate remains `HOLD_TREE_SOURCE_OUTCOMES_UNOPENED`. No row-level HPLC values, state patterns, AUCs, permutations or winner class were opened/computed.
