# Micro-accessibility v0.1 — active analysis gate

## What is now frozen

The first machine-readable registry contains seven independence-collapsed short-timescale *Camellia* systems spanning within-genotype sectors, developmental transitions, bud sports and within-species series.

The v0.1 analysis intentionally separates three questions:

1. whether mechanistic change packages recur across independent short-timescale systems;
2. whether explicit mechanistic state nodes are complete enough for a graph-topology null;
3. whether accepted-species macroevolutionary transition weights are identifiable enough for a micro-to-macro prediction test.

Only question 1 is executable in v0.1. Questions 2 and 3 are gated rather than filled with visible-colour proxies.

## Why this is stricter than the previous synthesis

The earlier directional synthesis showed repeated anthocyanin / competing-branch directions. The new registry makes the independence unit explicit and tests recurrence of multi-axis change signatures against a permutation null that preserves the marginal frequency of each pathway-axis change while destroying their cross-axis coupling.

This is a bias-control step: a significant recurrence result would mean that mechanistic packages recur more often than expected from the separate frequency of A/F/C/P changes alone. It still would not establish macroevolutionary reuse.

## Current claim boundary

Do not use white/red/yellow labels as mechanistic graph nodes. The primary micro-to-macro hypothesis remains untested until source/target biochemical states and admitted nuclear-tree macro transition weights are both available.

If yes, activate the degree-preserving graph null and macro congruence test. If no, preserve the block and prioritize candidate-free public RNA-seq module scoring to resolve state identities.
