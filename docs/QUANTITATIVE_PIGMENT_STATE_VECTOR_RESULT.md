# Quantitative pigment state-vector result

## Status

This document separates source-level findings from the quantitative patterns generated by `chun` and from hypotheses that remain to be tested.

## 1. Published inputs

Individual studies establish that Camellia flower-colour contrasts can involve anthocyanins, flavonols, proanthocyanidin-related branches, carotenoids and transcriptional/regulatory changes. These source-level results are not themselves `chun` discoveries.

The quantitative synthesis below uses reported processed tables only when phenotype orientation and table provenance are defensible. Assay-specific magnitudes are not pooled as though expression FPKM and metabolite abundance were commensurate.

## 2. chun quantitative results

### 2.1 Anthocyanin relative to flavonol is the most concordant current allocation axis

Four independent quantitative systems are currently admissible:

- `CSIN_WHITE_PINK`: anthocyanin-minus-flavonol direction is positive in 5/5 developmental stages, while individual FLS paralogs change direction through development;
- `CRETICULATA`: red-versus-white class contrast = `+4.5854` as the difference between anthocyanin and flavonol class log2 fold changes;
- `CJAPONICA`: crimson-versus-white contrast = `+5.0828`;
- `OIL_CAMELLIA_MULTI`: red-versus-white colour-material contrast = `+6.4196`, with source taxon identities intentionally not promoted because the source naming is conflicted.

Thus all four current independent systems are directionally concordant (`4/4`, exact two-sided sign `P=0.125`; Beta(1,1) posterior mean directional concordance `0.833`, 95% interval `0.478-0.995`). The small number of systems prevents a universal-frequency claim.

### 2.2 Proanthocyanidin is not a universal opposite branch

The anthocyanin-minus-proanthocyanidin contrast is positive in three interpretable systems, while `C. sinensis` is developmentally mixed (`3/5` stages positive).

Importantly, the oil-Camellia colour-material system has both anthocyanin and PA increasing from W to R; anthocyanin simply rises more strongly. Therefore PA must not be merged with flavonol into one generic `less-red competing branch`.

### 2.3 Carotenoid is an independent colour axis

`C. huana` provides a separate within-species colour-variant axis. At matched developmental stages, the red-outer-petal material has stronger carotenoid accumulation than the golden material:

- bud, `RS1 vs GS1`: 22 differential carotenoid metabolites, 21 higher and 1 lower in the red material;
- full bloom, `RS2 vs GS2`: 18 differential carotenoid metabolites, all 18 higher in the red material.

This system is kept separate from the anthocyanin contrasts. It demonstrates that a human-visible red phenotype can be produced within a carotenoid-dominated biochemical system and is therefore not synonymous with an anthocyanin-rich state.

### 2.4 C. sinensis shows why stage and paralog identity matter

Cross-table provenance checks on Zhou et al. reveal that Supplementary Table S6 systematically reverses BTP/ZJW labels relative to the mutually consistent S8/S9 tables. The S6 printed headers are therefore not admitted naively for genotype-effect estimation.

Using the defended orientation, DFR remains pink-directed across later developmental stages, while FLS direction depends on stage and paralog and LAR/ANR can also be elevated in pink material. This rejects a simple one-dimensional `anthocyanin up / all competing branches down` switch.

## 3. Repository-level discovery

The strongest current cross-study result is not merely `redder flowers contain more anthocyanin`.

It is:

> **Camellia flower-colour differences occupy a multidimensional pigment-allocation state space, and regulatory/flux changes provide repeatedly accessible routes through that space.**

A working state vector is therefore

`S = [anthocyanin, flavonol, proanthocyanidin, carotenoid, UV/spectral, reward/phenology, ...]`.

The first four dimensions are biochemical; UV/spectral and reward/phenology are ecological-sensory extensions and are not yet measured densely enough for a genus-wide fitted latent-state model.

## 4. Connection to existing hypotheses

### H_ACC — refined, not replaced

`H_ACC` should now mean accessibility of **module-state changes**, not accessibility of one red/white switch. Regulatory/flux recurrence remains the strongest mechanism-meta result, while the quantitative studies show that the accessible directions are multidimensional and can be stage/paralog dependent.

### H_STATE_ALIASING — strengthened

Human-visible W/A/Y coding demonstrably compresses distinct biochemical states. Evidence now includes:

- same visible red with different pollination/spectral function (`C. japonica` versus `C. rusticana`);
- large quantitative differences among red-like anthocyanin systems in Fan et al. Table S2;
- a red `C. huana` variant whose matched-stage carotenoid signal exceeds the golden phenotype;
- PA and flavonol not behaving as one interchangeable `non-anthocyanin` axis.

### H_SELECTION_TARGET — strengthened as a testable primary hypothesis

If ecology filters floral phenotypes, the biologically relevant target is more plausibly a biochemical/spectral state vector than a human hue label. This is still a hypothesis: superiority of the latent vector over hue must be tested on the same species/branches using standardized spectra, chemistry, rewards, phenology and effective pollination.

### H_MICRO_MACRO_REUSE — still open

The state-vector result does not establish that micro-accessible module changes are repeatedly reused on independent macroevolutionary branches. That requires nuclear branch histories and a node/module enrichment test against a predefined pigment-network background.

## 5. New problem generated by the quantitative meta-analysis

A one-dimensional transition model such as `W <-> A <-> Y` can confound at least two different questions:

1. did the human-visible colour category change?;
2. which biochemical module coordinates actually moved, and in what combination?

The macroevolutionary analysis should therefore compare visible-state histories with mechanistic state-vector histories rather than replacing one with the other without testing.

A decisive prediction is:

> **If molecular accessibility constrains macroevolution, transition branches should be enriched for movements along module directions already observed as labile in developmental/cultivar/sector systems, even after visible hue and lineage history are controlled.**

## 6. Claim boundary

Supported now:

- repeated regulatory/flux accessibility;
- quantitative concordance of anthocyanin relative to flavonol in four current independent systems;
- PA as a separable dimension rather than a universal inverse of anthocyanin;
- carotenoid as an independent visible-colour axis in `C. huana`;
- visible colour as a lossy compression of biochemical state.

Not yet supported:

- a natural frequency of these mechanisms across all Camellia transitions;
- a universal low-dimensional state vector;
- preferential reuse of these axes on independent macro branches;
- any particular ecological selection pressure on the vector;
- adaptive reactivation in a specific Camellia branch.
