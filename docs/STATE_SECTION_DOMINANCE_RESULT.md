# Fan 2026 full-table colour-state dominance result

## Question

Does the strong A/Y concentration across traditional sections represent broad repeated realization across several backgrounds, or is each state dominated by one major historical section?

This is a pre-phylogenetic diagnostic. It cannot infer origin counts.

## Result

Using the frozen 98-species / 17-section Fan 2026 section-colour table and 100,000 state-label shuffles preserving A/W/Y totals:

### A

- n = 25;
- 22/25 (**88.0%**) occur in `sect. Camellia`;
- expected maximum one-section share under the fixed-count null = **26.14%**;
- upper-tail P = **0.0000099999**.

### Y

- n = 17;
- 13/17 (**76.47%**) occur in `sect. Chrysantha`;
- expected maximum share = **28.08%**;
- upper-tail P = **0.0000099999**;
- all Y species occur in sections containing no A/W species in this source table (occupied-section purity = 1.0).

### W

- n = 56;
- largest contributor is `sect. Paracamellia`, 15/56 (**26.79%**);
- expected maximum share = **23.77%**;
- upper-tail P = **0.25747**.

Thus A and Y, but not W, are disproportionately dominated by one traditional section after state sample size is controlled.

## Connection to the molecular meta-analysis

The mechanistic meta-analysis shows repeated short-scale regulatory/flux accessibility. The full macro table shows that extant coloured states are not distributed as if that accessibility were realized uniformly across historical backgrounds.

However, this result specifically prevents an over-interpretation:

> recurrent molecular accessibility is **not evidence of recurrent independent macroevolutionary origins**.

The extant A pattern is largely one `sect. Camellia` radiation plus a small number of A species elsewhere. The extant Y pattern is largely `sect. Chrysantha` plus three smaller yellow-only sections.

The primary-tree analysis must therefore distinguish:

- one/few gains followed by retention/radiation;
- repeated independent gains;
- widespread gains followed by differential loss/persistence;
- lineage-specific gain permissivity;
- introgression/reticulation.

## Consequences for existing hypotheses

### H_ACC

Remains a micro/mechanistic result. Its claim ceiling should explicitly exclude macro origin frequency.

### H_MICRO_MACRO_REUSE

Remains **open**, not supported merely by repeated molecular mechanisms. It requires branch-level transition identification and gene/module mapping.

### H_LINEAGE_PERMISSIVITY

The full-table concentration strongly supports **non-uniform macro realization across history proxies**, but causal permissivity must be decomposed into generation versus persistence.

### H_Y_HISTORY

Strengthened: Y is both geographically constrained and strongly section-concentrated/section-dominated.

### H_FILTER

Cannot yet be assigned specifically to ecological persistence because one/few-origin radiation remains a competing explanation.

## Claim boundary

Traditional sections are not treated as monophyletic nuclear clades. This result is a robust screening pattern about source-table concentration, not an estimate of gain/loss counts, a proof of selection, or evidence for a specific reactivation history.
