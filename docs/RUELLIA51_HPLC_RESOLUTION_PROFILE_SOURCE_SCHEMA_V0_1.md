# Ruellia 51-species HPLC source-schema evidence v0.1

Before CHUN row-level HPLC outcome ingestion, the public article and author code establish the following source architecture:

- 51 neotropical *Ruellia* species;
- corolla reflectance spectrometry;
- HPLC measurements for Pelargonidin, Cyanidin, Peonidin, Delphinidin, Petunidin and Malvidin;
- a ddRAD-based evolutionary-history layer;
- source-code branch grouping `PEL = Pelargonidin`, `CYA = Cyanidin or Peonidin`, `DEL = Delphinidin or Petunidin or Malvidin`.

Only schema and author-defined grouping semantics were used to construct the preregistered hierarchy. CHUN did not use row-level compound values, realized branch-pattern frequencies, phylogenetic AUCs or profile winners to choose the mapping.

The exact source file and phylogeny file remain to be frozen in the next identifiers/schema-only preflight before row-level HPLC states are opened.
