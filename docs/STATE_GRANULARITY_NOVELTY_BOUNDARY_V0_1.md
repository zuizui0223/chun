# Flower-colour state granularity — novelty boundary v0.1

## Current scientific position

The program should **not** claim that it discovered that character coding matters, that visible flower colour can alias multiple mechanisms, or that state aggregation can bias phylogenetic inference. All three ideas have clear prior art.

The current defensible contribution is narrower:

> **Across independently reanalysed flower-colour radiations, fine-state phylogenetic organization remains reproducible while exhaustive competition among alternative coarse partitions rejects the idea that the investigator-selected binary boundary is a shared privileged representation. A prospectively tested coarse axis in Camellia then fails to validate uniformly, showing that the preferred coarse representation can change with source coding.**

This is a flower-colour-specific, multi-radiation **state-granularity / representation-dependence** result and falsification architecture. It is not yet a universal theory of discrete characters.

## Prior art that must be acknowledged

### 1. Character construction and aggregation are already a formal problem

Tarasov (2019; DOI `10.1093/sysbio/syz005`) explicitly treats ambiguity in discrete phenotypic character construction, hierarchical/hidden structure and Markov **lumpability**. In that framework, aggregating a fine Markov state space is lossless only under particular rate-structure conditions.

Vera-Ruiz, Robinson & Jermiin (2022; DOI `10.1093/sysbio/syab074`) go further for molecular characters and introduce a likelihood-ratio test of whether recoded DNA retains the Markov property. Their empirical examples show that recoding can distort inferred branch lengths when lumpability fails.

Therefore:

- `coding affects inference` is prior art;
- `state aggregation can be non-lumpable` is prior art;
- the present partition-capture statistic must **not** be called a formal lumpability test.

### 2. Flower-colour studies already recognize category aliasing

McCarthy et al. (2015; Nicotiana; DOI `10.1093/aob/mcv048`) explicitly avoid ancestral reconstruction of some pollinator-perceptual colour categories because the same category can be generated by different pigment combinations and therefore need not share one evolutionary history.

Ng & Smith (2016; Solanaceae; DOI `10.1111/nph.13576`) show that similar visible red flowers can be produced by anthocyanins, carotenoids or both, and test phylogenetic signal in pathway use. Visible endpoint and mechanistic state are therefore already known not to be equivalent.

Therefore the project must not sell `visible colour != molecular mechanism` as new.

### 3. Flower-colour comparative work already treats polymorphism and model/coding sensitivity

Ellis & Field (2016; Antirrhineae; DOI `10.1093/aob/mcw043`) identify polymorphic taxa as a challenge for discrete comparative analyses and run separate polymorphic and monomorphic treatments.

Imbert et al. (2020; Iris; DOI `10.3389/fpls.2020.569811`) use binary and polymorphic character representations and report pathological overfitting of ARD for some representations, switching to ER in those analyses.

Thus neither polymorphism sensitivity nor representation/model sensitivity is a new general observation.

### 4. Fixed coarse colour categories remain common in macroevolution

Many flower-colour studies still perform ASR and transition analysis using a fixed investigator-defined state alphabet. A project-relevant recent example is Fan et al. (2026; Camellia; DOI `10.1111/pbi.70442`), which reconstructs yellow/white/red flower-colour states and infers white ancestry.

The point is not that such categorization is intrinsically invalid. The unresolved question is **whether the selected aggregation is privileged enough for the intended evolutionary claim**.

## What this program adds

### A. Exhaustive alternative-partition falsification within real flower-colour systems

Instead of selecting one binary coding and reporting a sensitivity or a caution, the hierarchy-specificity control enumerates every non-trivial bipartition of the observed fine alphabet:

- Linoideae: 31 partitions of six hue states across 54 retained settings;
- Angraecinae: 15 partitions of five observed organ configurations across six retained settings;
- Antirrhineae: three partitions of the source-native pigment alphabet across 40 retained posterior-tree settings.

The biological partition is ranked against all alternatives using a frozen `capture` statistic.

The result is adverse to the initial hypothesis:

- Linoideae WHITE/non-WHITE: `NOT_ENRICHED`;
- Angraecinae primary GREEN/WHITE: `INTERMEDIATE`;
- Antirrhineae unpigmented/pigmented: `NOT_ENRICHED`.

This directly falsifies the stronger claim that the selected coarse boundaries form one shared constraining layer.

### B. Replication of the residual fine-state pattern across independent radiations

Despite the failure of coarse-boundary specificity, fine-state organization remains supported in three independent external radiations:

- Linoideae — hue;
- Angraecinae — floral-organ configuration;
- Antirrhineae — pigment class.

The general object that survives falsification is therefore not a particular binary partition, but **state-granularity dependence of macroevolutionary organization**.

### C. Prospective external failure rather than retrospective rescue

After exhaustive controls, YELLOW/non-YELLOW emerged post hoc as a frequent best partition in Linoideae and the best partition in Antirrhineae. The project did not promote that observation directly. It froze a Camellia validation criterion before calculating the Camellia scores.

Camellia returned `YELLOW_AXIS_MIXED`:

- strict wild-colour coding: YELLOW axis best on both topology treatments;
- dominant-colour sensitivity: ANTHOCYANIN axis best on both topology treatments.

This prospective failure is important evidence for the revised interpretation that the informative coarse partition is **coding/system dependent**.

## Novelty wording allowed now

Safe manuscript-level wording:

> We used multiple independently reconstructed flower-colour radiations to test whether common coarse colour partitions retain privileged macroevolutionary information. Fine-state phylogenetic organization was reproducible across systems, but exhaustive alternative-partition controls and a prospective Camellia validation did not support a common privileged coarse boundary. These results identify state representation itself as an empirical component of flower-colour macroevolutionary inference.

Also defensible:

> Our contribution is not the general observation that discrete-trait coding matters, but an explicit multi-radiation flower-colour test that ranks preselected coarse states against all alternative bipartitions and retains only the representation-level pattern that survives those falsification controls.

## Wording not allowed

Do **not** currently claim:

- “the first demonstration that character coding affects phylogenetic inference”;
- “the first demonstration that flower-colour categories hide mechanisms”;
- “the first lumpability test for flower colour”;
- “WHITE/non-WHITE is a universal evolutionary constraint”;
- “yellow/non-yellow is the general latent axis”;
- “fine-state organization proves molecular modularity or ecological selection”;
- a universal causal law of flower-colour evolution.

A priority claim such as “first exhaustive alternative-partition test in flower-colour macroevolution” remains **unverified**. The targeted literature search performed for this boundary did not retrieve a directly matching flower-colour study, but absence from that search is not evidence of priority.

## Theoretical connection and next gate

The natural theoretical connection is Markov-state aggregation and lumpability, but the current phenotype analyses are not formal lumpability tests. A formal extension would require an identifiable fine-state CTMC whose fitted rate matrix can be tested for aggregation compatibility; sparse multistate flower-colour data may make that difficult.

The more immediately executable biological next step is to test whether the recurring fine phenotype structure aligns with independently resolved **molecular pathway/regulatory-module** axes. Existing mechanistic benchmarks in this repository already show that repeatability can occur at exact-gene, regulator-class, pathway-module or broader-program levels, but their event units are heterogeneous and cannot yet be pooled into one estimator.
