# Micro-accessibility v0.1 — first null-model result

## Result

The seed registry contains seven independence-collapsed short-timescale *Camellia* systems. Five share the simple change signature `A up | F unknown | C unknown | P unknown` only after collapsing to the exact currently coded vectors, with three systems carrying the fully identical signature and the remainder containing additional branch changes.

The observed cross-axis mechanistic-signature recurrence score is **0.2653**.

A 10,000-permutation null independently shuffles the A/F/C/P change labels across biological systems, preserving the marginal frequency of each axis state while destroying their cross-axis coupling.

- observed recurrence = **0.2653**
- null mean = **0.2099**
- null SD = **0.0589**
- z = **0.94**
- upper-tail permutation P = **0.345**

## Interpretation

The current literature-coded micro layer does **not** show evidence that the same multi-axis mechanistic package recurs more often than expected from the separate marginal frequencies of anthocyanin/flavonol/carotenoid/proanthocyanidin changes.

This is different from the earlier directional synthesis. The earlier result that anthocyanin tends to increase toward redder states remains descriptive and reproducible, but it cannot yet be upgraded to a claim that complete molecular transition packages are repeatedly reused.

The main reason is visible in the registry itself: many non-anthocyanin axes remain `unknown` because the source studies measured different candidate sets. This is precisely the candidate-gene / missing-axis weakness that the candidate-free public RNA-seq reanalysis is intended to attack.

## Scientific consequence

The strongest defensible novelty claim is therefore not yet `the same molecular switch is repeatedly reused`.

The current result instead motivates a stricter hypothesis:

> short-timescale flower-colour accessibility may be recurrent at a coarse pathway level, but whether independent systems converge on the same multivariate pigment-state transitions must be tested from uniformly quantified public data rather than from nominated candidates.

## Next gate

Re-score admitted public petal RNA-seq datasets with the same predefined ortholog/module panel, reduce `unknown` A/F/C/P axes, then repeat this null model before activating the degree-preserving micro-state graph test.
