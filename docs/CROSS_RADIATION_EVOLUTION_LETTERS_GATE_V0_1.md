# Cross-radiation Evolution Letters gate — v0.1

## Decision

`EVOLUTION_LETTERS_MANUSCRIPT_BUILD_AUTHORIZED_NOT_SUBMISSION_READY`

The cross-radiation resolution-profile programme now supports a distinct manuscript architecture from the frozen Camellia Paper 1.

The working target is **Evolution Letters, Letter** because the paper is a concise general-evolution test built around a prespecified rule, prospective falsification, standardized many-clade replication, and cross-representation extension. Current journal guidance expects Letters to be approximately 5,000 words or less, with title <=30 words and abstract <=300 words.

## Why manuscript construction is now justified

The paper no longer rests on retrospective synthesis alone:

1. a cross-radiation intermediate-resolution ordering was converted into a frozen prediction;
2. an independent Iris radiation prospectively rejected that ordering;
3. a 51-clade standardized visible-colour batch yielded 28 completed exact profiles and heterogeneous terminal classes;
4. zero of four pre-outcome tree-geometry moderators qualified under the full-profile leave-one-out rule;
5. Petunieae supplies a completed biochemical cross-representation profile with a unique fine winner;
6. representation type remains explicitly non-identifiable because biochemical training contains one unit.

This sequence is sufficient to write and internally validate a general-evolution manuscript. It is not sufficient to claim that representation class itself predicts the winning resolution.

## Submission blockers

Before actual submission, all of the following remain required:

- replace bracketed literature placeholders with verified references;
- produce final main figures and supplement;
- archive a submission-specific code/data snapshot with a persistent identifier;
- complete author contributions, funding, affiliations and acknowledgements;
- rerun the journal/prior-art gate after the manuscript is complete;
- decide whether a second non-visible exact-profile result arrives in time to be included without changing the current inference retrospectively.

A second biochemical/non-visible profile is **desirable but not required for manuscript construction**. If obtained, it may open a preregistered representation-moderator test; it must not be used to post-hoc rewrite the existing Petunieae result.

## Claim ceiling

Allowed central claim:

> Flower-colour evolutionary predictability is representation dependent, but no universal optimal resolution is supported across the tested systems.

Not allowed:

- universal fine-resolution optimum;
- biochemical representations generally prefer fine resolution;
- Petunieae as a prospective replication;
- simple tree geometry can never explain resolution profiles;
- representation type predicts resolution profile;
- any priority/first claim based only on the current targeted prior-art audit.

## Separation from Camellia Paper 1

This is a new cross-radiation manuscript. The frozen Camellia AJB Paper 1 manuscript, authoritative-result registry and figure manifest are not edited by this programme.
